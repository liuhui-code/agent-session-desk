# 会话诊断

main 开发版：F6 进入管理焦点，大写 D 打开诊断；终端焦点的 D 保持原生输入。方向键／翻页查看，E 主动导出，Esc 返回；可配置 management.diagnostics。查看不重启原终端。

面板分别显示 terminal 的发现状态与当前 native client 的连接状态、版本／构建、最近发现／连接耗时、分类失败和最近事件。terminal available 不代表 Agent 存活或准备好；耗时包括 UI 调度等待。分类用于定位范围，不冒充根因。

默认仅在当前 UI 内保留最多 128 条事件，退出即丢弃，没有后台诊断进程、自动上传或逐帧日志。E 导出至 metadata.sqlite3 旁 diagnostics/diagnostic-N.json，最多四份、每份至多 256 KiB；固定临时槽也占容量。满额时检查并自行删除旧文件／中断残留后再导出，程序不覆盖已有文件。

可分享 JSON 使用固定字段白名单和 Session／Run 身份哈希引用，不含终端正文、输入／粘贴、名称、原始错误、命令／参数、目录、环境、凭据、恢复声明。编码时再次校验。面板本机路径不写入报告；版本号不证明实际二进制哈希。导出失败只显示固定分类，不自动重试；关闭面板后已请求的导出可能继续完成，迟到结果不会重开面板。

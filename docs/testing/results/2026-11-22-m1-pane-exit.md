# M1 pane 退出观测与元数据 v2

日期：2026-11-22。局部实现、未发布，完整 M0/M1 验收未完成。关联 FL-005、FL-011、FL-013；局部涉及 FL-006/016。

## 结论与实现

实现有来源的 pane 退出观测并持久化到 history，保留观测时间和原 Session/Run 关联；不返回未经验证的数值退出码。合同见 [ADR-0010](../../adr/0010-pane-exit-observations.md)，用法见[元数据说明](../../METADATA.md)。

固定 psmux 3.4.0 的 `src/format.rs`（提交 `20aa1d7254ee93f64dafa059ef89341d9767470a`）把 pane_dead_status/signal/time 写死为 0。Context7 返回 master 片段，因此精确行为对照固定源码，指纹存于 [source-manifest.json](2026-11-22-exit-evidence/source-manifest.json)。没有采用 master 新能力或把 0 当作真实码。

- 后端同时取得 pane_id/pane_dead，退出时再次核对关联。错 pane、畸形返回、截断、读取失败和关联变化降级 unknown，不写退出观测。
- Session 新增可选 pane_exit；history 在记录外层保存首次 pane_exit，历史 session.terminal_state 仍为 unknown。exit_code 为 null，observed_at 是产品观测时间，不是退出时刻。
- SQLite schema v2 追加一对一 pane_exits，保存首次观测，重复轮询只读。数值码、无来源或不匹配状态拒绝；显式 stop、目标消失或断连不制造退出事件。
- v1 在同一事务中追加表并升至 v2，保留身份与既有时间；冲突保留原库。未来版本仍拒绝，未提供降级迁移。

没有新增 agent 包装进程、常驻监测器、品牌适配或 UI 样式；原直接自定义 CLI 启动和 design tokens 约定继续有效。

显式 PowerShell 启动 fixture 后保留 shell：独立 fixture 已退出 7，但产品仅显示终端可连接，既无 pane_exit 也无 agent 就绪／完成声明。shell 的 PID、创建 FILETIME 和路径独立记录并核对，stop 后该身份消失；最终测试 namespace 的 list 为空。退出 fixture 的进程终止以受控退出记录及后端原 pane dead 为依据，不把 list 空当作任意完整进程树清理证明。

原生 store 测试 **14 项顶层测试通过，无 skip**，包含真实 SQLite 的 v1→v2 迁移、迁移冲突保留、首次时间、写锁和较强证据拒绝。前后两轮结果、命令与 fixture JSONL 见 [windows/](2026-11-22-exit-evidence/windows/)。

## 剩余边界

数值 agent/pane 退出码仍未知；没有可靠退出时间、agent 状态识别、任务结果回执或历史 UI。任意外部 respawn／服务器替换、完整升级／降级、掉电恢复、更多 shell 和系统兼容组合仍需验证。只在成功查询时记录，无消费者运行期间不承诺持续监测或完整事件历史。Unix tmux 没有新增原生执行结论。

归档文本规范化为 LF，日志 tab 展开、行尾空白去除；原始二进制 SHA 不变，归档校验见 [SHA256SUMS](2026-11-22-exit-evidence/SHA256SUMS)。

## 实现与结果

提供离线 metadata check [FILE]、backup DEST 和 restore SOURCE。只读检查已有库的产品标记、v1/v2 schema、完整性及外键；backup 保存全部作用域；restore 只写尚不存在的目标库，不覆盖空文件、已有库或故障库，不启动 Run。源 v1 保持原样，恢复库正常打开时才迁移为 v2。

快照通过只读连接 VACUUM INTO 同目录临时库，校验完整性后以硬链接非覆盖发布；正常失败清理自有临时文件，强杀可留下临时文件但不把它当正式备份。硬链接不支持时明确失败，不改成覆盖式重命名。快照已发布后若临时清理失败，错误明确说明已发布目标，不能误导重复覆盖。输出文件、TOML 与活进程不在数据库备份范围。

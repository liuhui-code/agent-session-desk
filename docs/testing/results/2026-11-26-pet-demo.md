## TDD 与本机局部结果

- 初始状态模型测试先因缺少 Kind／New／状态模型 RED，随后 GREEN；状态只能为 idle／approval／question／unknown，计数 1–99、固定 DEMO 标签，点击只循环合成姿态，不存在真实批准动作。
- 素材解码首先因假设正方形失败，改成偶数矩形仍失败；实际 PNG 尺寸核对后改为按边界比例分格。失败与复验日志保留，未修改原生成文件。
- 12 张实际渲染预览覆盖 4 状态 × 100/150/200%：透明区域和可见区域同时存在、所有 RGB 通道不超过 alpha、缓存／frame 尺寸有界、四姿态不同；人工查看了本轮 100% 待批准／待回答渲染。预览是 Go renderer 的图，不是 Windows 桌面截图。
- 负坐标显示器工作区／小工作区夹取、CLI 非法状态／计数／期限／位置参数／后端选项拒绝通过；非法调用没有创建 state 目录。
- internal/pet 与 internal/cli 完整相关包通过，提醒样机选择集 race、相关 go vet、go mod verify 通过；没有跑全仓库／全 UI 测试。
- 生产源码 500 物理行检查通过；本切片新增 Go 测试与原生驱动也逐一检查不超过 500。339 catalog 仍 designed/not_run，重新生成仅反映 ADR 索引，catalog 校验不执行产品测试。

## Windows 原生与桌面

最终 [run3 组件结果](2026-11-26-pet-demo-evidence/run3/tests.json)：Pet 6、CLI 1 顶层 PASS，fail／skip 为 0。包括实际 Win32 ABI 布局和 20 次 GDI surface 创建／选择恢复／释放检查；它们不等于 7 项完整桌面测试。

独立低权限 Interactive Task 启动样机，通过精确 PID／FILETIME／镜像和自有 HWND 观测。原生窗口实际 ex-style 为 `0x08080088`（layered／topmost／toolwindow／noactivate）；WM_MOUSEACTIVATE 返回 3。自有 HWND 消息执行普通点击循环、状态命令、隐藏和托盘回调恢复，没有向任何其他窗口或终端发送按键，没有剪贴板 API。

首轮 run1 的外部快照因 PowerShell 局部变量遮蔽 script 作用域未保存，其 all_focus_samples_unchanged 是空集合上的结果，**不作为持续焦点／资源通过**。该轮产品自身创建前后 foreground 相同，仅保留这个有限事实。修正后 run2 保存实际 18 份样本并加数量断言；改为专用 GUI 入口后最终 run3 再完成 18 份样本，18/18 的前台 HWND 不变。完整[失败／两轮复验](2026-11-26-pet-demo-evidence/)分别留档，不累加重复测试数。

最终 run3 原 PID `23180`／FILETIME `134401673936400064`，窗口 HWND `464626`；产品报告 17 次绘制，正常退出 0，原进程结束，无强制清理。只通过模拟自有 HWND 消息核验，不声称实体点击、拖动、完整菜单、IME、多屏热插拔或用户视觉接受已通过。

# F2 后恢复原模式与 Alt 模式保持

日期：2026-11-26。基础提交 `4eaca47`，依据 ADR-0044。按用户要求只跑受影响局部检查，不跑全仓、race 或 vet。

先增加真实 Model／异步终端服务边界的复现：终端／隐藏侧栏终端／管理模式分别 F2 后保存或取消，再 Alt+J/K。RED 中终端四个分支稳定落为 focused=false、sidebarHidden=false；管理分支与独立 Alt 模式保持通过。定位到 openSessionRename 强制管理焦点，两个关闭路径只重连而不恢复。Alt 本身未修改焦点，继承了 F2 留下的状态；不能外推其他断连／鼠标引发的管理模式。

改名待打开对象携带原焦点与侧栏显隐，在已接受输入排空前捕获；保存成功／取消统一恢复。保存失败继续保留弹窗，旧身份与不确定提交规则不变。隐藏侧栏旧测试改为恢复隐藏终端，代替此前 ADR-0043 的可见管理返回要求。相关改名错误路径测试还残留三处旧中文／混合文案断言，第一次扩大局部检查失败；仅将断言对齐已有英文产品提示，没有修改错误处理。

最终本机相关检查通过，范围为 F2／Alt 模式保持、改名保存取消／失败与输入排空、管理底栏、Ctrl+S 和长字段布局。生产单文件行数与 diff 检查独立执行。工作区原有未提交后端修改保留，交付由 clean git archive 构建排除。Windows 结果后补，未复现的退出或其他模式变化不宣称修复。

# 实时终端直接拖选的本地验证

日期：2026-11-24；基线 `3aa1aca`。按 [ADR-0030](../../adr/0030-direct-terminal-drag-selection.md) 扩展 ADR-0029，补 U18 的直接拖选入口。**本地合同／模型通过不表示 Windows、实体鼠标、系统剪贴板或整个上游体验通过。**

## 当前体验

已聚焦且未声明 WantsMouse 的实时终端，可无修饰左键直接拖选。按下只保存原内容锚点，同格微动和未拖动释放不写终端、不进入复制模式、不发起复制；第一次实际运动以原 pane 的 `copy-drag-begin` 交给原生选区，随后运动／释放沿已有 `pane-mouse` 和 FIFO。管理焦点第一次点击仍只聚焦。原生复制模式内已有拖选保持。

后端负责冻结页、选区、原生释放及复制事件，产品不另建 VT、历史或文本选区。固定 psmux 客户端在普通页内先自行选择，到边缘才交接；本产品首次运动就交接，是明确平台适配，进入冻结页时机及运动中的输出竞争仍需实测，不称逐帧相同。

动作接受不等于已观察到 CopyMode。旧实时帧在起始写入之后到达时，不清除同一手势；观察到原生模式再观察退出则立即取消，后来模式恢复不续接。未交接锚点遇到外部 CopyMode、WantsMouse、提示编辑或尺寸变化也取消，即使状态随后恢复。沿用视图代次、内容几何和原屏幕尺寸绑定、跨控件归属、键／粘贴／滚轮／模态／切 Tab 取消及不合成释放／复制的合同。断开与失败不重试，不把旧手势交给新 Run。

WantsMouse 来自认证帧中的声明，不证明子程序所有鼠标能力。声明鼠标的实时程序不被本次直接选择接管；其鼠标转发仍未实现。没有帧与命令间的模式锁：外部客户端可能让后端拒绝交接或改变后续接收者。不能从写入成功推断模式已切换、复制成功或系统剪贴板已保存。

无新依赖、样式值、服务、数据库或偏好版本。新能力为可选接口，缺少直接交接能力时不退回文字／方向键；原有原生复制模式指针能力仍可使用。帮助中增加直接拖选入口说明。

- 六个新 UI 顶层／含子测试共 12 个模型服务测试覆盖普通点击／微动、首次交接和原锚点、延迟模式帧、观察退出后不恢复、四类状态变化再恢复、原队列排空后切换及缺能力回退边界。既有五个复制指针顶层／22 个含子回归继续通过；原“live-program 不启动”样本按新范围明确为声明 WantsMouse 的实时程序，不删除管理／提示／边框／修饰等边界。

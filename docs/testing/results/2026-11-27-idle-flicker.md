# 2026-11-27 空闲蓝点闪烁

关联 [ADR-0057](../../adr/0057-terminal-activity.md)。上一版只处理了布局重排与前景色，遗漏了采样失败／过期和半圆动画的视觉混淆。

## 原因与修复

旧实现以同一个三秒阈值判断近期活动和采样鲜度，且任一 Preview 失败就删掉该观察；因此普通采样延迟会让蓝点消失，下次成功又出现。共享两秒 deadline 的固定顺序也可能让后排一直轮不到。现将鲜度分为十五秒，失败保留该窗口内旧观察且不更新 seen；轮换每次首目标。不增加轮询／并发／后台进程／历史缓存，仍最多八个摘要。超过十五秒、离开目标集合、换 Run 或 List 不可用仍不声称静默。

旧半圆帧 ◐ 等本来就有半边空白，选中时露出底色。受控 Windows Terminal 对照里，大号 ⬤ 又贴近单格边缘；现选择显示完整的单格 ●，活动动画换为独立蓝色 Braille 点状旋转。前景与背景逐单元格断言通过；不将该对照推断为用户原画面的唯一原因。

## 证据

- [采样 RED](2026-11-27-idle-flicker-evidence/sampling-red.log)：四秒间隔、单次读取失败均丢失蓝点。
- 新回归覆盖轮换首目标、失败保留、最终过期／目标剪枝及全部 idle/spinner 单元格颜色与选中表面。公平性初版测试未建立 workspace，得到 no sample；随后双重轮换抵消被测试捕获，修为只按 generation 轮换。保留中间失败，不计为通过。
- Darwin `go test ./internal/ui`、`go test -race ./internal/ui` 通过；源文件 500 行检查、diff 空白检查通过。按 UI 局部变更范围，没有跑全仓套件。
- Windows 定向六项通过，无 fail/skip。五项模型／渲染测试与一项真实 psmux fixture 流程分别记录；后者 23.88 秒，验证四秒无采样仍为空闲、真实输出／静默和 F6 重排。native 测试 SHA256 `fd9d3ad202d7120057f076b79fb961a06e33e263b5788603a3c63dc29684990b`。使用原开发 bundle／独立 namespace，不操作原日常 Run；自建 Run 的 Stop 没有错误。
- [受控字形截图](2026-11-27-idle-flicker-evidence/glyphs.png)：五行依次为大圆、单格圆、bullet、半圆、Braille。数据来自真实卡片渲染，仅合成标题；PS 打印到实际 Terminal。首次截图早于 child ready 为空白；第二次输出编码未设，出现问号；第三次显式 UTF-8 并等待 ready 才有效。公开截图裁掉窗口外内容；测试未访问剪贴板／修改设置。仅是字形对照，不是完整产品桌面接受。

# 分组来源与桌面证据

`manifest.json` 是全部允许归档文件的清单，记录原字节及脱敏 UTF-8/LF 哈希，PNG 原字节不变。`native` 为完整窗口／观察／清理白名单，`local` 为 RED/GREEN、实际来源／产品帧、helper、固定源码、构建及执行记录。Go helper 以 `.go.txt` 保存，避免成为额外 Go 包。

不包含数据库、auth key/port、设置备份、用户或测试历史内容、原剪贴板数据、测试二进制；第086捕获因程序字段显示测试用户路径而排除图片，仅保留脱敏回执及原图哈希。源码／模块174项指纹在构建、原生执行和归档后相同。脚本的个人目录／仓库路径已脱敏，复现时须映射相应的隔离环境。

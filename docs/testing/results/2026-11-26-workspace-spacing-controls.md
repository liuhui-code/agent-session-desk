# 外层留白、F2、固定管理底栏与 Alt 切换

日期：2026-11-26。基础提交 `cc131d7`，依据 ADR-0043，关联 FL-003/004/012/016/018、TC-UI-010。按用户要求只做相关局部检查。

共享外边距为左右两列、顶部一行，导航根 gutter 迁入共享框架；侧栏隐藏后内容保留同等外边距。管理模式固定一行快捷键并从原生／列表尺寸中扣除；普通终端模式不常驻。F2 复用当前活动／所选会话或组的既有改名路径。Alt+J/K 复用原视图切换和 FIFO 输入归属，兼容旧 Ctrl+PgUp/PgDn，不修改 Windows Terminal 全局键绑定。

新增行为先 RED：旧隐藏视图 x/y=0、内容贴边、管理底栏不常驻、F2 未进入改名、Alt 未切换。实现后相关检查通过，包含顶部留白不命中、12/49/63/120 列渲染边界、F2 活动目标／组取消、A/B/A 两个原 writer 各自恰好一次草稿且无 Alt 键泄漏、导航／分割命中及原生拖选坐标。拖动测试一轮仍期待旧的管理高度，但该场景保持终端焦点；修正观察器为新终端高度 31，没有改产品焦点语义。日志见[证据目录](2026-11-26-workspace-spacing-controls-evidence/)。

本机 Go 1.27.4 darwin/amd64；不跑全仓／race／vet 或完整 Windows 套件。生产源码 500 行及 diff 检查独立执行。工作区已有未提交后端修复保留，不纳入此 UI 构建。Windows 原生及交付结果后补，不把模型通过当成实际切换／改名接受；339 catalog 状态保持。

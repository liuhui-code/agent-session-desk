# 外层留白、F2、固定管理底栏与 Alt 切换

日期：2026-11-26。基础提交 `cc131d7`，依据 ADR-0043，关联 FL-003/004/012/016/018、TC-UI-010。按用户要求只做相关局部检查。

共享外边距为左右两列、顶部一行，导航根 gutter 迁入共享框架；侧栏隐藏后内容保留同等外边距。管理模式固定一行快捷键并从原生／列表尺寸中扣除；普通终端模式不常驻。F2 复用当前活动／所选会话或组的既有改名路径。Alt+J/K 复用原视图切换和 FIFO 输入归属，兼容旧 Ctrl+PgUp/PgDn，不修改 Windows Terminal 全局键绑定。

新增行为先 RED：旧隐藏视图 x/y=0、内容贴边、管理底栏不常驻、F2 未进入改名、Alt 未切换。实现后相关检查通过，包含顶部留白不命中、12/49/63/120 列渲染边界、F2 活动目标／组取消、A/B/A 两个原 writer 各自恰好一次草稿且无 Alt 键泄漏、导航／分割命中及原生拖选坐标。拖动测试一轮仍期待旧的管理高度，但该场景保持终端焦点；修正观察器为新终端高度 31，没有改产品焦点语义。日志见[证据目录](2026-11-26-workspace-spacing-controls-evidence/)。

本机 Go 1.27.4 darwin/amd64；不跑全仓／race／vet 或完整 Windows 套件。生产源码 500 行及 diff 检查独立执行。工作区已有未提交后端修复保留，不纳入此 UI 构建。Windows 原生及交付结果如下，不把模型通过当成实际切换／改名接受；339 catalog 状态保持。

补充隐藏侧栏的 F2 回路：旧编辑器退出后会留下管理焦点但侧栏仍隐藏。针对去掉恢复可见行的 RED 复现后，编辑器明确恢复导航可见，GREEN；不变更名称、不写终端输入。前后日志单列，不将已通过的基础测试替代此分支检查。

最终源提交 `1beea51` 由 clean `git archive` 构建，未带入工作区后端修改。Windows 原生仅执行此次相关 14 个 UI 顶层检查：14 通过、0 失败、0 跳过；不是完整套件。测试 exe SHA-256 `71ba8e58f628f745c0ea0a6bca082bdee22faa4a0b758f6ea18c2b3b45a7e791`。交付 exe `asd-spacing-1beea51.exe` SHA-256 `cfab783f200c5bbfaa5a1fd9b4e50ce30a970a80d34b3fbfa0d7d099f0e03144`。版本化安装保留旧 exe／manifest 备份，BOM manifest 经默认 PowerShell 读回及全文件散列校验；新旧发现的 6 个 Session/Run/backend 身份一致。

实际 Windows Terminal 有界桌面验证已完成：直接 exe 交接打开最终版本，旧管理窗口正常关闭，原 Run 继续。首次脚本因无 BOM 的框线字符导致 PowerShell 5.1 解析失败，未进入窗口动作；后续只读脚本一度叠加 BOM，仍无输入动作。修正的是验证脚本编码，不是产品。前两轮用卡片单像素作 Ready 条件停下，阶段标记也未覆盖反向切换，不能把失败阶段直接解释为产品未切换或单纯连接延迟。单独只读观察确认 B 活动标识、原生提示符、`20303b` 底色、无连接／只读错误，管理进程仍为 1；后续假定仍在 B 的恢复被状态守卫拒绝，没有发送按键。失败回执单列保留。

最终恢复先重新核对当前活动行只能是注册的 A/B，再以活动标识、实际 PS 提示符及无连接／只读错误共同确认目标。7 个保留快捷键操作完成 A→B→A、F2 打开原名称并 Esc 取消、管理底栏、Ctrl+S 隐藏／恢复及 F6 回终端；没有提交终端命令或访问剪贴板。管理色实测 `38576b`，顶部首行为空；导航活动标识和隐藏后 PS 提示符的左边均为屏幕 x=40 px，证明该窗口内共享外边距，不外推任意 DPI 下与 WT chrome 的像素接受。取消后 6 个 Session/Run/backend 身份、名称和 title revision 均未变，注册 A/B 原 PID/FILETIME/路径仍一致。新版保留打开供用户查看。最终回执里的 terminal RGB 是预期常量，B 的实际颜色另由只读观察提供，不将该字段当成末帧重新采色。

这是普通 shell、当前固定 Windows Terminal 和本次按键的有限证据。没有复现先前偶发切换退出，因此未纳入已有未提交后端补丁，也不声称修复该问题；真实 agent、其他输入法／宿主、完整视觉与资源接受仍开放。

最终只读审计：产品管理进程 1 个，只有 `--inside-terminal` 子进程、无遗留交接 launcher；发现仍为 6 个会话。本轮所有明确命名的临时任务均不再存在，包含补查的两次恢复任务。源码／ADR 已提交 `6439815`、`1beea51`，本报告后续提交只补证据，不更换已安装 exe。

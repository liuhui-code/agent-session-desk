# M1 最小 Session/Run 元数据执行报告

日期：2026-11-22。局部实现、未发布，完整 M0/M1 验收未完成。关联 FL-005、FL-011、FL-013，局部涉及 FL-001/006/015/016/019。

## 实现与合同

[ADR-0009](../../adr/0009-session-run-metadata.md) 固定 modernc.org/sqlite v1.62.0、内嵌 SQLite 3.54.1、libc v1.80.1，使用 Go database/sql，无产品 C 工具链或常驻进程。SQLite DELETE journal、FULL synchronous、单连接、1000ms busy timeout 和 cache_size=-1024 是实现设置，不是已测量预算或掉电保证。

[store](../../../internal/store/) 通过事务保存 Session/Run 两表，保持身份和作用域，拒绝冲突、未来 schema、外来库、损坏文件和缺失必需表；拒绝时不重建或覆盖旧文件。保存名称、入口显示信息、后端关联、入库时间及显式停止确认，不保存 argv、env 或终端正文。重复发现只校验相同记录，不重复写入或改变原入库时间。

[manager](../../../internal/manager/) 在启动前检查当前可写性；后台已创建而提交失败时返回准确 Session/Run ID，提示不要重复 start。两个资源不构成原子事务，进程在崩溃窗口仍可能存在但没有元数据；后续成功 list 可以从活后台补录。停止成功但数据库更新失败也单独报告，不伪装全部成功。没有自动重启、重放或自动清理用户进程。

CLI/TUI 的 list、preview、attach 和 stop 仍以实际后台核对身份。新增 `asd history [--limit N]` 读取持久元数据，即使后端二进制不存在也可用；默认 100 项，上限 1000。历史 terminal_state 恒 unknown，停止确认不升级为 agent 退出码或任务完成。命令与路径合同见[使用说明](../../METADATA.md)。

## TDD 与本地验证

按逐行为 RED → GREEN 推进，失败与复验保存在 [tdd/](2026-11-22-metadata-evidence/tdd/)：

| 行为 | 失败与修正 |
| --- | --- |
| 关闭重开、身份与状态 | 新接口接通，持久记录保持 Session/Run，历史不保留在线状态 |
| 作用域、身份冲突与两表事务 | 原先冲突被忽略；核对绑定、拒绝覆盖并回滚半份父记录 |
| schema 与文件损坏 | 原先仅初始化新文件，既有文件未校验；增加 application_id、版本和必需表检查 |
| 显式 stop 与历史 | 增加准确 Run 的停止确认，重复发现和重复确认不清除历史或改写首次时间 |
| 读取和字段边界 | limit 必须 1–1000，拒绝无效身份和超界字段 |
| 后台／数据库非原子副作用 | 当前写故障阻止创建；创建后关闭真实 SQLite 连接模拟提交故障，报告 ID 并保留后台 |
| 失联与空列表 | 不把连接失败或列表缺失推断为停止／完成，不将历史合并进实时列表 |
| 重复发现锁争用 | 已有记录仍尝试写锁导致 SQLITE_BUSY；改为先只读核对，再仅对新记录进入写事务 |
| 必需表被移除 | application_id/version 正确仍被接受；补充必需列查询校验，保留坏库 |

并发控制使用四个独立真实 SQLite 连接并发创建／提交，核对保留全部记录、integrity_check、journal 和 sqlite_version。外部真实 SQLite 写锁验证 busy 有界失败且保留已提交记录。manager 的终端替身只证明协调逻辑，关闭连接故障不等于实际磁盘满／只读卷测试。

history 的首次 CLI 检查还受到新增模块的缺失 go.sum 项阻断；完成依赖下载、tidy 后 CLI 与完整套件通过。这一轮 setup failure 单独保留，不称为 history 产品行为失败。接口尚未存在时的编译失败也只算接通接口的 RED。

Go 1.27.4、macOS amd64：`go test ./...`、`go test -race ./...`、`go vet ./...`、`go mod verify` 通过；catalog 派生校验、16 项 Python 工具测试及 500 行检查通过。实际日志见 [checks/](2026-11-22-metadata-evidence/checks/)。引入驱动同时按模块图升级 x/sys 到 0.49.0、x/sync 到 0.24.0；没有静默改变 Charm 目标版本。

# ADR-0017：侧栏密度设置与独立界面偏好

- 日期：2026-11-23
- 状态：已接受（ADR-0014/0016 上游体验还原范围内的实施决定）
- 关联：FR-03、FR-11；FL-003、FL-012、FL-018；ADR-0003、0007、0008、0014、0016
- 实现与验证：四种密度、设置输入隔离和独立偏好保存已接入；实际执行与剩余门槛见[本轮报告](../testing/results/2026-11-23-sidebar-density-preferences.md)。不代表完整视觉或发布验收。

## 背景与来源

固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 `embedded_sidebar.go`、`settings_panel.go`、`userconfig.go` 和 `hotkeys.go` 提供 full／compact／minimal／auto，默认 compact；设置热键为 `S`，左右／h/l 调整、空格轮换，改变后立即保存，Esc／S 返回。之前只迁入默认卡片，尚不足以还原这部分体验。

ADR-0007 的显式启动模板保持只读，不能为保存一个界面选择而重写包含 executable／args／env 的用户文件。既有 TOML 配置、SQLite 元数据、有界输出的资源边界不变。

## 决定

1. Tab 侧栏支持 full 三行、compact 两行、minimal 一行；auto 根据当前可见会话项、可用宽高，从三／二／一行中选择能全部容纳的最丰满密度，不读取上次计算结果。低于 28 列退为一行，高度不足时保留完整标题。渲染、滚动窗口和鼠标命中共享同一行高；最后元信息行使用 `╰`。元信息仍只是终端观察和程序文件名，不迁入 agent 品牌或状态猜测。
2. 只在管理焦点下使用 `S`。设置独占按键、粘贴和鼠标事件；终端焦点的 `S`、空格和方向键仍属于目标程序。打开前排空已接受的原终端写入，再关闭客户端，不停止 Run；返回时重新核对原目标。后台发现不得在设置期间重连隐藏终端。
3. 沿用上游选项顺序、调整／即时保存／退出交互、强调标记、radio 选择下划线、圆角与调色板，全部样式经 tokens。只呈现本产品已有的侧栏设置，不迁入品牌、账户、远程等业务面板；窄窗只显示当前 radio 选项，短窗优先选中值、保存状态与返回提示。这是通用终端／响应式的适配，完整视觉接受仍需对照与用户评审。
4. 保存到元数据所在目录的独立 `ui.toml`；`--state-dir` 已有隔离规则同样适用，没有当前目录搜索或额外配置扫描。首次缺文件默认 compact，用户首次更改才创建文件。格式为 `schema_version = 1` 和 `sidebar_density = "compact"`，键严格大小写；未知密度按上游退到 compact，未知版本／字段／错误类型／语法拒绝。读取限 4096 字节，这是防御边界而非资源预算。
5. 按一次只有一个保存任务串行执行，快速按键保留最新选择；已有保存完成后再保存最新值，不创建无界写队列。只在保存成功后更新有效密度。保存期间退出等待已接受的最新选择；失败显示未保存、保留原有效值，并允许退出／再次显式调整，不自动重试。
6. 写入同目录临时普通文件（0600 请求模式），Sync、关闭并重新解析验证后以 Rename 发布；拒绝覆盖无效或未来格式，失败清理临时文件。多个合法设置写入者采用最后成功发布者优先；不提供跨进程 CAS、配置与数据库联合事务、断电耐久或所有 Windows 文件系统的原子性保证。Windows 权限仍取决于目录 ACL，不把 Unix mode 等同于 Windows ACL。
7. 首次读取错误不阻止管理终端：使用 compact 并提示，设置页保留原因；后续保存重新验证该文件，不能静默覆盖无法识别的偏好。TOML 解析错误不回显用户源行／值；OS 错误可带路径。偏好保存不写启动模板、数据库、Run 或终端输入。

## 代价与边界

独立文件避免重写启动模板；代价是配置不集中在一个文档。后续增加 UI 偏好须演进 schema 和保留字段，不能直接覆盖未来文档。本轮不实现主题文件、启动模板保存／迁移、Tab 顺序持久化、设置热重载或完整故障恢复；原有未决门槛保留。

本产品仅保留最新屏幕，密度变化不增加输出历史或后台常驻进程。此变更的功能测试不能代替当前构建的完整资源预算与长稳测试。

## 验证要求

- 四种密度、28 列边界、auto 重复计算／缩放、选择可见与元信息行点击；短窄窗保留选项与错误。
- `S` 在终端中仍是字面输入；设置不泄漏键／粘贴，不中断已接收写入、不触发自动重连，错误不伪装保存成功。
- 保存／替换／重读、临时文件清理、无效／未来文件拒绝及不覆盖，CLI 默认路径、UI 关闭重开恢复选择。
- Windows 原生普通 shell 的独立草稿、Session/Run/PID 保留与实际原子文件 API 行为；更完整故障、目标 agent、字体／主题／同尺寸上游画面仍需实际验证。

实际帧对照补充（2026-11-23）：运行未修改的固定上游，校正工作区终端框／页脚行带、设置外宽 66 列、新建外宽 86 列及普通／首次 padding 2／1 行，窄窗保留帮助与焦点键。原始单元格经 Windows 同显示配置回放，六帧逐行一致，两个 49 列末格缺口保留；产品前后实机与 82 个原生 UI 顶层测试见[报告](../testing/results/2026-11-23-upstream-visual-comparison.md)。这是既有还原决定的修正，不更改终端所有权／依赖；上游 Darwin 参考、静态回放和 fixture 均不等于真实 agent 或完整视觉接受。

# ADR-0037：目录建议交互与有界最近启动目录

- 日期：2026-11-24
- 状态：已接受还原范围内的实施决定；实现／平台证据另记
- 关联：FR-01/02/03/11/12；FL-001/002/003/012/013/015/016/018/019
- 扩展 ADR-0007/0014/0016/0017/0023；不改变命令行参数、Run 或终端所有权

## 决定

1. 迁入固定来源 group_dialog.go／newdialog.go 的路径建议、pathfuzzy.go 的匹配／合并意图及 utils.go 的有界目录完成。分组默认目录遵循首项预选、上下／Ctrl+N/P 循环、Tab/Enter 采纳、Esc 先隐藏再取消；新建目录保留自定义路径项、编辑／浏览／预填软选择以及 Tab 的文件系统轮换，不能把两个表单简单合并成同一组按键。
2. 语料包括有界最近明确启动目录和已知分组默认目录；不从名称／终端画面猜测 cwd，不把旧 Run 的目录当作当前进程目录。当前 Session/Run 元数据没有 cwd，不修改其历史语义。最近目录是建议缓存，不是完整启动历史；按使用先后保留最多 20 项，同名目录不混淆 Session/Run。
3. 建议缓存放元数据目录下、按 backend scope 哈希隔离的独立 recent-dirs TOML 文档 v1；至多 20 条，每条至多 4096 UTF-8 字节，总读取至多 192 KiB。仅明确成功的 UI／CLI 启动记录目录；失败／不确定启动和选中建议都不写。写失败不把已启动进程变成启动失败或自动重试。只读加载不改文件，坏值／版本拒绝覆盖，同目录验证临时文件后发布；多个合法进程最后成功发布者优先，不提供跨进程 CAS。此 UI 建议文件与其他偏好一样不在 SQLite 元数据备份中。
4. 自动文件系统建议仅针对用户当前输入的路径形查询；用户明确按 Tab 时也可补齐普通相对目录名，一次非递归扫描至多 10000 条目录项，结果最多 20 项；普通词只匹配已有语料。支持本机相对／绝对、Windows 驱动器／UNC 和本用户 ~ 路径，不执行 shell／zoxide，不展开任意环境变量或其他用户目录。隐藏项仅在用户输入点前缀时出现；符号链接／.. 保留实际文件系统含义。控件不接收控制字符，源目录错误不输出私有路径内容。
5. 每 UI 至多一个实际目录扫描，输入变化合并为一个最新请求；取消／换字段／换弹窗后迟到结果不能改输入或采纳旧选择。系统调用不能保证可中断，旧扫描返回前不建立并行扫描，UI 可继续输入或关闭。异步语料加载保留已明确导航候选的路径身份，不把同一行号换成别的目录。最近缓存加载每次弹窗按需读取，写入单 writer、有界合并；父 context 结束后不继续新任务。
6. 弹出列表沿来源的圆角、Comment／Cyan／Purple 角色、选中标记和短屏 3／常规 5 项（边缘空间不足时进一步减少，保留选中项）；全部值经 design tokens。列表锚定输入并在屏幕内翻转／裁切；极小视口不展示不可操作的候选，保持字段编辑与退出。能力／主题变化只换样式，保留查询、选择与焦点。
7. 沿来源使用 sahilm/fuzzy v0.1.3 的稳定匹配，MIT／提交／校验和单列，不引入旧 Charm UI 依赖。Context7 未匹配该库，依据官方发布／README 与锁定源码核对。新建补全未完成的非空本机目录按 Tab 保持当前字段；异步等待期间最多顺序保留 16 个键／粘贴事件、总文本 64 KiB，Escape 可立即取消。外平台路径只作提示，不扫描本机 cwd；进入极小视口时退出浏览并恢复编辑焦点。深色浮层作者 #292e42 的固定来源 TrueColor 输出实测为 #282e41，显示副本与 ANSI 4／256 索引 17 单列；浅色 #dcdde2 沿来源对应 ANSI 7／256 索引 188。原有 ui.toml v7、SQLite v5 不变，新增文件仅为有界 UI 建议配置；完整来源 frecency／品牌最近会话恢复不自动迁入。

## 验证

按最近缓存、目录扫描、单任务时序、分组／新建各自键位和浮层逐行为 RED→GREEN；覆盖不执行／不发终端输入、成功后记录、写失败不重启、晚到／关闭、非法文件与字段、Unicode／长路径／缩放／能力变化，并核对固定来源实际组件。缓存、Go 模型／文件系统与原生 Windows／实体输入／UNC／默认色恢复及完整接受分别记账。

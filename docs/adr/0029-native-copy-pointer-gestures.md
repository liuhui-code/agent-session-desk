# ADR-0029：原生复制模式的鼠标手势

- 日期：2026-11-24
- 状态：已接受方向；实现与平台验收另记
- 关联：FR-02/03/04/11；FL-002/003/005/012/013/016/018/019
- 扩展 ADR-0015/0016/0018；不改变终端托管或历史所有权

## 决定

1. 先落实原生复制模式内的无修饰左键按下、拖动和释放。管理 `v` 或已有滚轮入口进入原生模式，后端继续负责选区、复制光标、滚动及释放复制。正常终端的直接拖选、目标程序鼠标、修饰键／其他按钮及边缘驻留自动滚动继续开放，不把此切片当作完整鼠标还原。
2. 固定 psmux `20aa1d7254ee93f64dafa059ef89341d9767470a` 的 `pane-mouse PANE_ID BUTTON COL ROW M|m` 使用原 pane、零基内容坐标；左按／拖／释放分别为 `0 M`、`32 M`、`0 m`，随后刷新屏幕。Go 独立适配，不复制 Rust 实现、不模拟方向键、文字或 Enter。
3. 手势只从活动、已连接、终端焦点、已观察 CopyMode 的可见内容内开始；管理焦点第一次点击仍只聚焦。坐标不含产品边框／Tab／页脚，拖动可在防御界限内越过原内容边缘，由后端解释。搜索提示编辑中不开始手势。
4. 手势绑定连接代次及开始时内容矩形；其后拖动／释放由原手势消费，不因越过 Tab、侧栏或分隔线改为管理动作。只接受一次开始，重复释放不重发。所有指针动作经既有有界 FIFO，与按键、粘贴、滚轮和切换排空共享顺序。
5. 键盘／粘贴／滚轮、resize、失焦、进入模态、切换／断开或模式失效清除本地手势；不合成释放、不自动复制、不跨 Run 续接。已接受动作仍按原队列处理，未知／失败不重放；原生模式及未完成选区可能保留，用户可 Esc 取消。无按钮运动不是释放证据，清除手势而不复制。
6. 帧中 CopyMode 是观察，不是模式锁。后端按收到事件时的模式解释；外部客户端并发改变模式仍可能改变接收者。前后帧不能消除此间隙，不能声称鼠标协议永远不会到达子程序。真实后端、实体鼠标、Unicode 选区、边缘滚动、系统剪贴板及模式竞争须独立实测。
7. 复制继续走 ADR-0018/0028 的单 OSC52 写入器；界面不读取系统剪贴板、不保存第二份历史、不新增样式常量、依赖、服务或存储版本。来源协议、Go 传输、模型输入和 Windows 桌面证据分别记录。

## 验证

以原 pane 的真实内存流合同、输入 FIFO、内容坐标、越界与重复回执、切 Tab／resize／模态隔离作为本地行为证据。Windows 上传授权未解决期间不换通道绕过；本地通过不升级为 ConPTY、系统剪贴板或完整体验接受。

# ADR-0043：统一工作区留白、F2、管理底栏与 Alt 会话切换

- 日期：2026-11-26
- 状态：已接受，依据用户五项明确反馈
- 关联：FR-03/11/12，FL-003/004/012/016/018
- 部分替代 ADR-0041 的贴边／悬浮提示与 ADR-0042 的管理底栏隐藏选择；身份、终端原生输入与独立 Session/Run/Tab 保持

## 决定

1. 工作区采用共享外层左右两列、顶部一行留白。导航与内容的原点由同一 geometry 计算，隐藏侧栏仍保留外边距；移除导航内部重复的根 gutter。窄／短窗缩小留白以保留可用区域，不产生负尺寸。外层 Windows Terminal 的字体／profile 保持，本决定不把单元格留白声称为任意 DPI 下与宿主 Tab 像素完全一致。
2. 管理模式固定显示底部快捷键，预留一行，内容和列表不画入该行；终端输入模式普通底栏隐藏。错误／操作回执及原生搜索提示保留优先级，不依赖 hover。沿用已有 footer 选择和宽度降级，正常宽度固定显示 Alt+J/K、F6 等导航键，F2 作为改名提示。
3. 工作区 F2 打开改名。管理焦点改所选会话或组，终端焦点绑定当前活动 Run 对应的逻辑 Session，不能误改另一个后台选中项。隐藏侧栏发起改名时恢复导航可见，避免编辑后管理动作指向不可见选择。复用已有输入排空、名称预填、取消／保存和 revision 核对；连接／发现错误或切换／排序在途时不启动旧编辑。r 兼容与错误时 r 重查保持。
4. Alt+J 下一个、Alt+K 上一个**已打开会话视图**，在管理／终端焦点均可达；原 Ctrl+PgUp/PgDn 保留兼容。复用原 activateWorkspace 的 FIFO 排空、连接身份核对与不重放路径，不创建或停止 Run，不更改 Session 手动排序。关闭的视图仍须由列表明确重开。只保留这两个 Alt 字母组合，不改宿主全局按键设置；其他 Alt 输入仍按既有规则归属原程序。
5. 绘制、原生尺寸／光标、导航命中／滚轮、分割拖动、复制搜索光标与程序鼠标共同使用新原点。管理底栏和外层留白不是子程序输入区域；已有原生拖动／释放仍保留原目标。样式尺寸仍集中在 design tokens。

## 验证与边界

Context7 的 Microsoft Terminal 索引包含不同阶段的快捷键规格，不能据此断言固定 1.25.3131.0 的全部实际绑定；最终以本机 Alt+J/K、F2 实际到达程序为证据，不静默改宿主设置。局部模型检查包含隐藏后留白、窄窗／顶部空白、固定底栏、F2 原目标／取消、Alt A→B→A 的原输入归属，以及导航／分割／原生鼠标坐标。Windows 模型／实际桌面分开记账，见[执行报告](../testing/results/2026-11-26-workspace-spacing-controls.md)。

SQLite v5、ui.toml v7、启动默认／最近配置和固定终端运行库保持。真实 agent、其他宿主／键盘布局／IME、完整鼠标与视觉接受仍开放；旧切换退出问题没有复现时不能仅凭改键声称已修复。

# ADR-0008：UI 样式统一由 design tokens 管理

- 日期：2026-11-22
- 状态：已接受（Accepted），用户明确要求 UI 样式用设计 tokens 管理
- 关联：FR-03、FR-11、FL-003、ADR-0001、ADR-0005
- 实现与验证：当前管理器样式已集中；[实际报告](../testing/results/2026-11-22-m1-config-tokens.md)。新版本 Windows 桌面视觉评审仍待做

## 决定

所有产品 UI 的样式选择均从 [design_tokens.go](../../internal/ui/design_tokens.go) 取得：颜色、粗体、间距、列宽范围和比例、响应式断点、最小显示尺寸、边框／分隔标记、选中标记、截断符号与预览 tab 宽度。组件角色通过 [styles.go](../../internal/ui/styles.go) 组合 tokens，视图不定义新的颜色或直接创建样式。新增组件也遵循这一规则。

先保持现有 Tokyo Night 配色与默认布局，每个 Model 持有值副本；无全局可变主题，不加入主题守护进程或 watcher。当前入口是开发期修改类型化 tokens，尚无用户主题 TOML、运行时编辑器或热切换承诺。调整尺寸后必须验证受影响的短窗口和断点组合。

终端单元格归一化、索引、行数和身份算法中的 0/1，以及文案内容，不是样式 token。预览中的 agent 输出属于终端内容，不能用管理器主题改写其 ANSI 配色。资源上限、刷新周期与命令超时也不是设计 token。

## 后果与验证

统一调整入口避免散落的视觉魔数。现有宽字符／emoji、精确视口测试继续覆盖默认布局；另验证修改 tokens 确实改变可见标记、菜单间距和布局，以及不同 Model 互不污染。这些 Go 渲染测试不代替真实 Windows 字体、IME、attach 恢复或用户视觉接受。

Agent Deck 派生调色板移动后继续保留原版权、提交与 MIT 归属，更新复用清单，不重新归为原创。

# ADR-0057：终端活动标识

2026-11-27；已接受。用户选择终端活动，名称后转圈，静默蓝点。

参考 iTerm 的活动/新输出分离，不复制源码（GPL）。https://iterm2.com/documentation-preferences-appearance.html 的蓝点是未读；本产品按用户要求静默蓝点。不是 Agent idle/ready。

psmux 当前 window_activity 是创建时间，不能使用。先比较已有有界 Preview：显示区最多8个，每轮一个串行worker，2秒deadline；只存SHA256/时刻，不复制历史。变化3秒内转圈，鲜度超过3秒/断连不标静默；未知不显示。首次基线。离屏不监控，不承诺未读；相同输出/只控制序列可能漏掉。不能作为任务完成/自动投递条件。

一条150ms动画链，只在活动期。颜色沿用蓝色token；样式统一入口。无数据库/Host变化。准确原始输出计数待后端合同，不假装支持。

2026-11-27：按用户视觉反馈将静默符号改为较大⬤，独立饱和蓝 #1677ff；集中token，活动帧不改。

选中反馈修复：组标题选中不插入额外gutter；所有活动标识用蓝色。尺寸/连接变更递增采样epoch，拒旧样本并3秒内仅建基线，避免重排文本误算输出。该窗口会短暂隐藏真实输出变化，随后恢复；不增加timer/历史。

# ADR-0024：删除组结构并收纳逻辑成员

- 日期：2026-11-23
- 状态：已接受，落实用户要求的固定上游体验；实现／验证另记
- 关联需求：FR-03/04/10/11/12；关联能力：FL-003/004/005/011/012/013/018/019
- 扩展：[ADR-0023](0023-persistent-groups-and-membership.md) 与 ADR-0009/0016；不替代单会话移动的原 Run 核对

## 背景与决定

固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的组标题 d 使用默认选中 Cancel 的确认框；DeleteGroup 删除该组及子组，把成员移入默认组，明确不终止终端。产品应恢复该流程，同时保留稳定身份、离线历史成员和并发修改的边界。

1. 管理焦点选中组标题按 d，沿来源红框、黄警告、删除／取消按钮和键位。默认取消；←／h 选删除，→／l／Tab 选取消，Enter 激活当前项，y/Y 明确确认，n/N/Esc 取消。默认组只显示不能删除的居中提示。终端焦点的 d／y 等仍交给原程序；本切片不把 Session 行 d 解释成停止或删除。
2. 先读取只读预览，显示实际组名、将删除的组数量（含子组）、逻辑成员数量及默认组当前名称。成员包含已退出／历史 Session，不以当前终端发现作为完整成员清单。预览未完成或失败时不能确认，取消不写元数据。
3. 预览以稳定根 ID、完整作用域组树及受影响成员 ID／归属／版本计算 SHA-256 变更印记；成员流式处理，数量不代替成员身份，印记不是授权凭据。组树已有 256／16 层防御边界，读取／写入保留调用上下文期限，不声明资源预算达标。
4. 确认后在单个 SQLite immediate 事务重算并比较预览全部字段及印记。组树或受影响成员的变化（含 ABA）拒绝，要求返回重新核对，不自动重试。随后将子树成员归入保留 default ID，成员版本各加一，再按子组优先删除组行；版本耗尽或任何 SQL／投影失败整体回滚。Session、Run、名称／启动快照、输出记录和真实进程不删除。
5. 组删除是逻辑容器元数据操作，Manager 不调用终端 list/start/stop/input；它不适用单 Session 显式移动的在线 Run 条件。提交结果只投影 UI 已观察的 Session 行，保持运行字段原样，不声称事务同时证明终端存活。SQLite 仍 v4，元数据检查／快照包含结果，输出文件仍不随数据库备份。
6. 弹窗前排空已接受输入，再断开客户端；确认只绑定原弹窗与根 ID。提交中不能重复确认／丢弃，失败保留错误。成功后保留原 Tab／Run，更新逻辑归属、选择默认组，并接回原活动终端；已观测更新的版本和运行实例不得被迟到回执回退。
7. 仅清理实际已删除 Group ID 的折叠记录，保留其他作用域／未知组的偏好；沿既有 ui.toml 串行写入。数据库和偏好文件不构成原子事务，保存失败明确显示，不能撤销已提交删除或暗中重复操作。临时 Tab 展开仍不自动保存。

## 比较与代价

只按根组版本确认无法发现新增子组／成员，可能超出已审阅影响；只数成员无法识别同数量替换或 ABA。完整快照印记避免无界成员副本，代价是扫描本作用域成员元数据，超时必须拒绝而非省略成员。整棵组树变化均使预览失效，是比来源更严格的并发适配。

不删除会话／Run 或终端内容，也不要求后台进程配合容器编辑。停止、归档、删除历史、持久队列和真正 agent 生命周期继续分别定义／验收。

## 验证与依据

TDD 验证默认取消、预览只读、跨重开结构／成员、完整事务回滚、两个连接竞争、新增／移动／ABA、默认组保护、原输入／Tab 和更新版本。固定来源组件与真实 Windows 普通 shell 流程分开记账，失败与清理同样保存；实现不等于完整体验或发布接受。

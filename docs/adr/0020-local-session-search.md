# ADR-0020：沿用上游本地搜索，以原 Session/Run 打开终端

- 日期：2026-11-23
- 状态：已接受，落实 ADR-0014 的界面／交互还原及 FL-004 会话查找
- 关联：FR-02/03/04/11；FL-003/004/005/012/018/019
- 细化 ADR-0014/0016 的辅助导航与输入归属；不改变终端托管、元数据 schema 或消息状态

## 背景与来源

固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 `internal/ui/search.go` 提供 `/` 本地搜索弹窗、原生输入、十行结果窗口、方向键／Ctrl+J/K 和 Enter／Esc。`internal/session/discovery.go` 的 `FilterByQuery`／`localQueryDistance` 提供 Unicode 子串容错排序。此前产品已接入 Tab 和通用终端，但没有会话搜索入口。

沿用这两个固定 MIT 来源，按稳定 Charm v2 改编；实际源码哈希、组件渲染、TDD 和 Windows 结果见[报告](../testing/results/2026-11-23-session-search.md)。不迁入上游 Recall、账户／远程或未实现的 agent 状态推断。

## 决定

1. 管理焦点下 `/` 打开按需本地会话搜索。终端焦点下的 `/` 原样发送给目标程序；原生复制模式的 `/` 仍是后端历史搜索。不是增加日常聊天输入框。
2. 弹窗使用当前作用域已有的实时发现列表，只匹配名称和程序路径，显示名称及程序文件名。查询不读取终端正文、结构化对话或历史数据库；程序路径只在内存匹配，不额外持久化。没有 agent 状态过滤、分组／cwd 搜索或 Tab Global 入口，不伪造尚不存在的字段。
3. 查询最多 100 个 rune／400 字节，只接受单行粘贴。匹配前 Unicode 小写化并裁去查询首尾空白；不做 NFC/NFD 归一化。1–3 rune 必须精确子串，4–5 rune 允许一个编辑，更长允许两个；按最小编辑距离稳定排序，精确子串优先，同分保持发现顺序。组合字符按 rune 计数，容错命中不等于规范化。
4. 按固定上游保留强调色圆角外框、输入框、结果背景／选择标记、结果计数和居中布局。上游 v1 的外宽迁移为 v2 的 62／55／41 列（120／63／49 列窗口）；数值、颜色、字重、内边距与装饰统一进入 design tokens。标题／帮助本地化，缺少 Recall／分组元信息导致的高度差逐项记录。极窄／短窗按实际边界裁切并隐藏越界光标，不沿用上游最小宽度溢出。
5. 使用已有 textinput v2 的真实光标，禁用组件独立读系统剪贴板的快捷键，仅消费外层明确 PasteMsg。输入焦点属于搜索窗；键盘、鼠标与粘贴不落入底层 Tab。F6、Tab 及 Ctrl+PgUp/PgDn 不切走搜索焦点。Esc／Ctrl+C 取消；q 是查询正文。没有额外常驻进程或后台全文索引。
6. 打开前沿现有串行边界完成已接受的终端写入，再关闭当前客户端连接；Run 和程序自己的未提交输入由 psmux 保留。取消回管理焦点，接回原 Run；选择后经既有 Tab 入口验证并连接相同 Session/Run。查询和搜索 Enter 不发送给 CLI，不创建新 Run。
7. 后台发现继续刷新结果；选择绑定完整 Session/Run，重排保留同一对象。所选 Run 消失／替换时清除选择并提示重新选择，Enter 不自动落到首行或同名新 Run；用户明确移动或更改查询后才形成新选择。零结果或不可交互对象不执行进入、停止或启动。

## 验证与保留范围

验证查询与终端输入隔离、未提交草稿、精确／容错排序、空查询与零结果、后台重排／Run 替换、窗口边界及原身份。原生 Windows UI 模型测试和真实 shell 桌面另记，不将模拟服务当作真实 agent。

重命名、分组、归档、搜索持久历史、其他后端以及完整上游视觉接受仍是后续工作。产品当前模型没有 cwd／group 字段，不为搜索凭空扩大 schema；命名／分组的完整规则仍待独立决定。本次只关闭本地查询的规则未决项，不提升完整 FL-004 或发布状态。

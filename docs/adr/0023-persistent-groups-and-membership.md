# ADR-0023：稳定分组身份、嵌套创建与会话归属

- 日期：2026-11-23
- 状态：已接受，落实 ADR-0014；实现／验收按实际报告记账
- 关联：FR-03/04/10/11/12；FL-003/004/005/011/012/013/018/019
- 扩展 ADR-0009/0012/0016/0021/0022；SQLite v4 与独立 ui.toml v3

## 决定

1. 分组具有稳定 Group ID，名称、父组、创建顺序、可选默认目录和版本独立保存。Session/Run/Tab、后端标签和原启动快照不变。组名不是后端或文件系统寻址依据；路径只用于展示。默认组使用保留 ID，允许名称展示演进，不能移动到其他组。
2. SQLite v4 追加作用域内的 groups 和 session_groups。成员关系属于逻辑 Session，历史展示当前归属，不改原 Run 的 cwd／命令／时间或输出记录归属。移动核对原完整 Session/Run/Backend/程序和预期成员版本；ABA 仍冲突。同值操作不增加版本，不记录无界操作日志。元数据提交不与后端存活构成跨资源原子事务。
3. 沿固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 g／M、上下选择／Enter／Esc、组标题展开折叠、上下文根组／子组及创建默认目录交互。Tab 保持主工作区；组操作不会向终端发送文本。创建弹窗 Tab 只切名称／目录字段，↑↓ 切根组／子组，按固定源码实际行为适配，不能沿用过时注释中的 Tab 切组模式。
4. 名称沿来源清理规则：字母、数字、空格、连字符、下划线保留，点／路径分隔符转连字符，其他字符移除；空的清理结果为 unnamed，空原始输入仍拒绝。新增输入拒绝控制字符和非法 UTF-8。原始名称输入最多 4096 UTF-8 字节；清理后名称最多 50 code point／200 UTF-8 字节，目录最多 4096 字节，均为明示的防御边界，不是资源验收预算。
5. 同一父组的清理后同名同目录创建返回原组；目录不一致则拒绝，不能以重复创建偷偷改写配置。空组保留，组按持久创建顺序展示。默认目录只影响显式创建的新 Run，不向正在运行的 shell 注入 cd；用户仍可在启动表单覆盖或清空目录。组内启动前验证目标组；原 Run 和初始成员归属在一个元数据事务提交，外部进程创建仍不原子，失败报告实际身份且不自动重启／停止。
6. 分组树与活 Session 投影从同一元数据读取事务取得，后台发现继续保留原启动快照。UI 的选择、组弹窗和异步结果绑定稳定 ID；迟到发现不回退已提交归属。新对象最多 256 组／作用域（含默认组）、16 层，为防御性界限；不当作性能／可用性接受门槛。
7. ui.toml v3 在密度、模式和默认组折叠之外保存按稳定 ID 排序的自定义组折叠集合，读取上限增至 16 KiB，沿用一个整文档串行保存队列。v1/v2 只读加载，显式修改才发布新格式。切 Tab／搜索只临时揭示目标祖先，不自动写偏好；即使先前保存尚在进行，临时揭示也不排队追加保存。只有明确接受的偏好操作进入后续保存队列。组名变化不丢失折叠归属。
8. 新库直接 v4，v1/v2/v3 在单事务逐级迁移；冲突结构回滚，旧源与只读检查不被偷偷重写。check／snapshot／restore 保留旧版本兼容及组／成员元数据，输出文件仍不随元数据备份。旧二进制拒绝未知 schema，不直接回退打开 v4。

组重命名、删除／重排及完整上游体验仍属于整体目标，不能以创建／移动切片宣布完成。实际本机、原生 Windows 模型、普通 shell 桌面、真实 agent、IME、资源和发布证据分别记录；Accepted 不等于实现或验收完成。

## 实现与证据

当前已接入持久树／成员版本、事务迁移与恢复、管理 g／M、组内启动目录、嵌套侧栏和 ui.toml v3。实际本机与 Windows 模型检查分别记于[执行报告](../testing/results/2026-11-23-custom-groups.md)；新桌面、来源画面对照、完整组编辑与整体接受仍开放。

# ADR-0074：有界指令片段库与原终端显式粘贴

2026-11-28，已接受。用户选择常用指令／提示词片段库；关联 FL-002／012／015／018、FR-02／11，补充 ADR-0003／0016／0060。实现及实际证据见[本轮报告](../testing/results/2026-11-28-instruction-snippets.md)。

## 决定

复用 Go 单体、固定 TOML 解析器、搜索弹层样式和原终端 FIFO，不引入依赖、常驻 Host、文件 watcher、全文终端历史或新聊天输入区。首版通过外部编辑配置文件维护片段；产品只读。数据库与原有配置版本不变。

- 全局文件为当前 metadata.sqlite3 同目录的 `snippets.toml`，遵循已有 state／scope 定位。
- 项目文件为本次核验原 Run 的 pane 当前目录下 `.asd/snippets.toml`。不从 UI 进程 cwd 猜测、不遍历父目录或 Git 仓库；当前目录不可获得时只加载全局并标明范围。
- schema_version=1；`[snippets.ID]` 内 title／body。正文按字面值保留，没有环境变量、命令、模板或文件插值。每文件最多 64 项／256 KiB，每项正文最多 4096 UTF-8 字节，标题最多 120 字节；ID 为 1–64 个小写 ASCII 字母、数字、下划线、连字符。拒绝未知／错误大小写字段、空正文与 ESC／NUL／C1 等控制字符，正文允许 CR／LF／Tab。
- 两个可选文件按需重新加载，项目在前，各自按 ID 排序；相同 ID 分开显示 Project／Global 来源，不隐式覆盖。任一现存文件无效则整次加载失败，不能静默使用半份库。默认不写入示例或创建任何文件。
- 默认 F7，沿 keybindings.toml 的 workspace.snippets 可重绑／禁用。仅对活动原生 Tab 开放；管理焦点时也以明确展示的活动终端为目标，与辅助侧栏选择分开。
- 已接受输入未完成时拒绝打开并提示等待；只保留现有原连接与一个加载操作，采用固定读取上限和 5 秒上下文截止；底层不可中断读取可能更晚返回，返回前不允许开始第二次加载。弹层消费键盘／鼠标／粘贴及导航激活；取消恢复原焦点与侧栏，取消加载，旧结果不能重开界面。
- 搜索后 Enter 预览，第二次 Enter 才粘贴；Esc 从预览返回列表，再 Esc 取消。预览支持滚动，短窄窗口提示放大并拒绝盲确认。确认时复核原 generation、Tab、Session／Run／backend／command、连接、实时屏幕及发现可用性；失联／替换或 copy/search 模式不写入，不自动接回后重放。
- 粘贴复用原 FIFO 的单次 Paste，确认键不发给目标，不追加 Enter。多行粘贴仍可能被 shell 当作执行输入，预览必须明确提示，不能保证目标程序只编辑不执行。提示仅声称请求排队；不推断 Agent 接受或任务完成。

## 样式和资源

复用 token-owned searchBox／input／selected 等角色；预览行数、最小可确认尺寸、Tab 显示空格统一进入 design_tokens.go。原始正文和显示投影分开，换行／Tab 的预览转换不得改写发送字节。

库与查询状态仅在弹层保留，关闭后释放；加载无额外后台刷新，每次打开至多读取两个文件，不复制正文到结果数组。上限是防御限制，新增运行内存、峰值及实机体验需实测，不能把原有长稳或固定读上限作为新功能资源通过依据。

## 验证范围

TDD 保存加载、实际模态粘贴归属、全局激活跨模态和短窗口的 RED／GREEN。检查缺文件、错误 schema、控制字符、条数／字节边界、原 Run 变化、加载取消、原生粘贴与无 Enter、布局边界和重绑。真实 Windows 输入与桌面结果另列，模拟不代替真实 Agent 或发布接受。

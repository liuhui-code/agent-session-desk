# ADR-0027：持久化工作区比例与临时拖动预览

- 日期：2026-11-24
- 状态：已接受方向；实际实现／验证单列
- 需求：FR-02/03/10/11；能力：FL-002/003/012/013/018/019
- 扩展 ADR-0016/0017/0022/0023；SQLite 仍 v5

## 决定

1. 沿固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 split_config.go：管理焦点 `<`／`>` 每次调整 5%，10%–90% 夹取；拖动中只预览，拖动结束后保存一次（含无按钮松开、丢失松开后的无按钮移动、重新点击／滚轮）。终端焦点同名字符仍交给原程序。现有 design tokens 继续拥有绘制和尺寸值，不新增视图样式数值。
2. 独立 ui.toml 升至 v4，新增 `sidebar_percent` 整数：0 表示自动，10–90 表示手动列表占比；其余值／类型拒绝，错误不输出配置正文。沿既有有界读取、严格字段版本、同目录验证临时文件和 rename 发布。v1–v3 只读加载时默认自动，不改写；显式偏好修改才写 v4，旧版拒绝 v4，不删除旧字段或改启动模板。多进程仍是最后成功替换者生效，非 CAS、无断电承诺。
3. `=` 明确保存 0，恢复管理 35%／终端 18% 的自动选择；手动比例跨焦点／重开保留。宽双栏和既有上下布局共用列表占比，最小面板／窄单列约束保持。未在拖动中时，启动、焦点变化、缩放、悬停和普通单击不触发额外保存；只有用户显式改变选择落盘。
4. 拖动预览与已接受的完整偏好分开。键盘、点击／滚轮、无按键移动、缩放、主动切视图结束拖动时保存最后预览，松开事件不依赖按钮或坐标，避免 X10／漏事件导致比例丢失或跳到边界。主动用户事件经同一收尾入口；非用户触发的连接失败／外部关闭不启动新的保存。仍在拖动中的预览不能被其他密度／分组保存夹带。恢复尺寸与终端原输入仍走既有串行通道；不缓存或重放程序正文。
5. 与密度、模式和折叠共用一个整份偏好串行写入器；保存中接受的新选择合并为后续最新快照，不并发写同一文件。旧成功回执不得回退新比例或当前拖动预览。保存失败恢复最后成功偏好、取消预览、显示错误并取消等待退出，不自动重试；退出等待所有已接受的偏好及终端写入完成。
6. 原生终端 Run／Tab 身份和终端生命周期不变，比例修改只发送已有尺寸事件。真实 Windows／桌面、原程序及资源门槛与本地模型分开记录；前轮停止复验的上传审批拒绝仍有效，不换通道绕过。

## 取舍与依据

上游把 preview_pct 写入主 config，失败静默且当前值继续生效；本产品用互补的 sidebar_percent、独立 ui.toml、可见失败与串行快照，避免覆盖启动配置和并发丢失其他偏好。不保存每个鼠标移动，不把临时预览当显式选择。自动与手动必须有不同存储值，否则重新打开无法保留焦点自适应。

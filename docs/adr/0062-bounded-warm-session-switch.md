# ADR-0062：有界末帧与会话回切优先级

2026-11-27，已接受。用户反馈切换会话会先出现 Connecting 页面且明显变慢。细化 ADR-0016 的显示保留、ADR-0057 的可选采样调度；不改变单一活动连接、原生输入或终端进程所有权。

## 决定

- UI 进程保留最近四个原 Run 的最后受验证屏幕，总保守计费不超过 512 KiB。按 Session/Run/backend 完整身份取回，独立复制 slice 与字符串，不保留超大或复制／搜索状态屏幕；不写盘，不保存历史，不维持后台终端连接。关闭 UI 清除。总量包括字符串与结构体的保守开销计费，不是整个进程 RSS 接受预算。
- 已访问目标在连接期间显示自己的末帧，并用现有底栏标明 read-only last observed；无实时光标／鼠标输入权限。新的键盘输入仍遵循既有有界连接缓存，验证失败清除，不自动重放旧输入。未访问、被淘汰、超界或不可用的目标仍可出现连接提示。
- Open 的首屏与连接结果一起提交，继续按 generation 拒绝旧回执；首屏失败关闭新客户端，保持既有错误／不重放边界。没有用别的 Run 的画面填充新目标。
- 后端只读一次原身份元数据，复用完整 attach 检查；一条 display-message 同时返回活动 pane ID／dead，严格匹配原 pane 和 live 标记。保留版本探测、固定 bundle 哈希、实际 PID/FILETIME/path／DLL／宿主检查与鉴权首帧校验，不缓存控制授权、不选择 pane。
- 开始连接时取消可选活动采样；连接阶段不启动新的活动／发现轮询，显式改名等成功后的元数据协调仍执行。一个活动采样 worker 和原每秒节奏保持，不新增计时器或常驻进程。

## 依据与范围

Context7 仅提供 psmux master 的 display-message／pane_id／pane_dead 文档线索，不能当作固定版本兼容。实际以原 Windows 开发 bundle 及原 pane 消失拒绝测试验证组合查询；官方发行物／整体发布门槛不提升。

实测基线重连首屏空载 1.19–1.51 秒、发现／采样负载 1.73–2.71 秒，后续同探针分别为 0.47–1.19 与 1.28–1.75 秒。各三次，非统计性能保证。末帧只提供立即可见的上次画面，验证连接尚未完成；资源、真实 Agent、所有宿主／字体和更长运行仍另验。

实际失败、回归和 Windows 交付见[报告](../testing/results/2026-11-27-warm-session-switch.md)。

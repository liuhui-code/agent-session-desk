# ADR-0068：工作台有界诊断与主动导出

2026-11-28，已接受并实施。关联 FL-012／013／015／016／017、FR-11／12；细化 ADR-0003／0016／0060。

用户同意优先实现会话状态、最近失败和可分享诊断，随后接恢复入口。采用既有 Go／Bubble Tea 消息循环和文件接口，不增加依赖、后台 Host、轮询或终端查询。

## 数据与边界

- UI 更新线程中的环形缓冲最多 128 条观察。仅记已通过 generation 核对的发现／连接回执、终端流／输入失败及窗口 resize 事件；连接与发现耗时是本工作台发起到收到回执的观察耗时，包含调度等待，不冒充纯后端耗时。
- 固定字段包含 UTC、操作类型、耗时、失败分类、构建 revision／dirty／Go／OS／架构／后端版本及目标终端／客户端观测。Session／Run／backend 完整身份只产生哈希引用，不把终端正文、键盘／粘贴内容、原始错误、标题、命令／参数、目录、环境、凭据或恢复声明写入报告。编码再次验证字段白名单；分类不是根因证明，terminal available 不代表 Agent ready／存活。
- 默认只在本 UI 进程内保存，UI 退出后不承诺留存，不提供崩溃／启动失败的完整历史。没有逐帧记录、每会话后台进程、自动上传或自动落盘。

## 界面与导出

- 管理模式大写 D 打开独立诊断面板，可用 keybindings.toml 的 management.diagnostics 改键／禁用；终端焦点的 D 保持原生输入。固定 E 导出、方向键／翻页滚动、Esc 返回；不增加内容区顶部描述。
- 打开／关闭面板不主动断开健康客户端或改变原目标。输入／粘贴／鼠标被面板消费；现有已接受输入继续按原 FIFO 完成，状态回执继续处理。面板期间尺寸变化只更新面板，返回时才对原工作区协调尺寸。提醒激活只恢复工作台，不越过面板导航或答复。
- 主动导出到元数据库旁 diagnostics 目录，最多四个固定 JSON 槽，每份编码最多 256 KiB。相同槽的独占临时文件、完整关闭后硬链接非覆盖发布；固定临时槽也计入容量，进程中断后不自动删残留或重用它。目录拒绝符号链接／Windows reparse point，Root 限制子路径，已有文件不覆盖；满额时由用户检查并删除旧文件后再导出。
- 导出使用不可变快照和一个异步请求；关面板不取消已经明确请求的导出，迟到结果不重新打开面板／覆盖新的面板状态。报告路径仅在本机面板显示，不写入可分享 JSON。错误显示固定分类，满槽给出可操作说明。
- 数据库和配置 schema 不变；报告 schema_version=1。不更改恢复协议、消息状态、审批或 Agent 授权。

## 依据与验证

Context7 返回 Bubble Tea beta.6 与 v1 片段，只作 Cmd／消息循环线索；代码仍采用仓库锁定的稳定 2.1.2，无升级。实际编译、隐私哨兵、并发文件发布、窄窗和原生终端验证见[报告](../testing/results/2026-11-28-diagnostics.md)。整体发布、真实 Agent、长期 RSS、故障启动和退出后持续诊断不由本切片接受。

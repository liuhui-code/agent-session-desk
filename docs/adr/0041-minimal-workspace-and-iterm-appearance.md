# ADR-0041：单一侧栏、无框工作区与 iTerm 外观

- 日期：2026-11-25
- 状态：已接受，依据用户对实际 Windows Alpha 的五项明确反馈；实现与实机交付结果另记
- 关联：FR-03/11/12，FL-003/012/016/018
- 部分替代 ADR-0014/0016 的固定主界面标题、重复 Tab 条、边框和常驻提示；部分替代 ADR-0032/0035/0036/0037 的 Dark 来源色值。其他身份、输入、原生终端与存储合同保持。

## 用户决定

侧栏已有会话与分组，顶部重复标题没有必要；去掉产品顶部标题区和右侧边框；底部平时隐藏，鼠标悬浮时再出现；中文及整体文字缩小，采用用户 iTerm 的字体与配色。这是新的产品外观依据，不再把旧上游常驻 chrome 的像素一致性作为这些区域的接受条件。

## 实现合同

1. 侧栏是唯一可见的会话导航。逻辑 Session、Run、Tab 继续独立；Ctrl+PgUp/PgDn 切换原视图，管理焦点的 `[`／`]` 调整本次逻辑视图顺序；侧栏选择、双击／Enter、搜索仍沿原身份合同。移除顶部 Tab 条、其新建／关闭鼠标热区及拖动状态，不留下不可见点击目标。管理 `n` 新建、`x` 只关视图，`d` 仍需明确停止确认。
2. 主工作区没有产品标题行、重复 Tab 行、终端圆角框或常驻底栏空白；原生内容按新的同一份 geometry 计算绘制、尺寸、光标和鼠标坐标。保留侧栏分隔／拖动及窄窗管理列表／堆叠行为。弹窗仍有自己的边界，不把子程序主动绘制的边框当作产品 chrome 删除。
3. 普通提示仅在窗口内收到无按钮底边 motion 后覆盖最后一行，内部移开／键盘／粘贴／尺寸变化时隐藏。覆盖不改变原生尺寸、不发送输入、不积累屏幕历史；鼠标点击／滚轮在已显示提示表面消费。已开始的原 pane 拖动／释放仍按原路径发送，不被底边截走。遮盖原生光标所在末行时暂不绘制光标，移开后恢复原输出／光标。
4. 搜索编辑提示及其光标、断连只读说明、保存失败和明确操作回执仍可占一行，不能为隐藏提示而吞掉关键反馈。表单／帮助的输入归属、排空及故障不重放保持。窗口外没有 VT motion 的情形不推断已经收到 leave；本轮实机证据只关闭窗口内移出的门槛。
5. Dark 采用从本机 iTerm Default 读取的黑底 `#000000`、正文／光标 `#bbbbbb`；UI 辅助灰度均放在 design_tokens.go，不普遍加粗。原终端显式 RGB／索引／粗体不改写。Light 保留原方案；System 的观察生命周期与选择持久化不改，Dark 分支使用新配色。ui.toml v7 与 SQLite v5 不变。
6. 外层 Windows Terminal 的字体及 16 色表由专属 profile 设置，不修改系统默认终端或其他 profile 的选择。用户本机 iTerm 是 Meslo LG S DZ for Powerline 12、非 ASCII 字体覆盖关闭；Windows 初版选用同一用户现有字体、10pt 正常字重作为更紧凑的视觉试值，并明确不是两平台像素完全相同。中文缺字仍由宿主回退。字体只装当前用户，不随公开发行物或 Git 分发。
7. 旧源色值／边框／拖动证据保持历史，不改写旧结果。新增 iTerm 灰度在 ANSI/ANSI256 下有明确索引选择；原有 Light 显示适配保留，无色模式继续移除管理属性。弹窗叠加在中文双宽边界时补齐精确前缀格宽，保持 Value／Position 和原输入不变。

## 验证与限制

2026-11-26 导航层级补充（用户决定）：去掉工作区导航顶部“会话 分组／会话 平铺”总标题及其横线，不保留标题空行；实际命名分组及折叠入口保留。导航首项与原生内容从首行对齐，窄窗列表／堆叠也不加描述头。同步删除列表鼠标和滚轮的标题行偏移，点击仍绑定原 Session/Run。内容区全给原程序，不新增产品顶部描述。

选中会话／组的左侧三角取消，以行内颜色标识；会话列表选中用原 surface 深灰底，当前内容所属会话用独立低饱和蓝灰底（Dark `#20303b`、文字 `#bcd4e2`；Light `#cbdce8`、文字 `#23465a`），当前内容的细竖标保留。同项同时选中及活动时优先活动配色；移动列表选择不切换内容、不注入输入。颜色及有限色映射统一放在 tokens，整张卡片含缩进与元信息连续填色。

UI 快速调整阶段按用户要求先实现可见效果并记录 ADR，仅做直接相关的渲染／命中局部检查，不默认跑全仓测试或 Windows 全量验证；后续发布验证另行记录。本轮局部结果见[导航外观报告](../testing/results/2026-11-26-navigation-appearance.md)。

2026-11-25 用户继续要求弱化侧栏与内容区之间的竖线：分割线不是视觉重点。补充决定：工作区分割线统一使用 border 色（Dark `#333333`），终端焦点、悬停与拖动均不再改用正文／accent 亮度；悬停与拖动仅保留粗线形状提示。上下各留两行空白，由 `workspace.dividerInsetRows` 定义；不足五行时不绘制线条。分隔列宽、终端尺寸和原有拖动命中范围保持，空白端部不缩减内容区。旧焦点高亮合同由此项明确替代，旧实测保持历史。局部验证见[分割线报告](../testing/results/2026-11-25-quiet-divider.md)。

按行为保存 RED→GREEN，回归逻辑视图排序、原 Run 输入、侧栏命中、尺寸／光标、长字段、提示覆盖恢复、原生拖动跨底边、主题保存／能力变化；常规／race／vet／模块与原生 Windows UI 分别记账。个人 Alpha 的更新只正常退出管理界面，不停止后台 Run；新产品使用版本化文件，旧产品、原数据和终端 bundle 保留。

本决定不接受完整上游视觉、实体硬件、所有 IME／字体回退／DPI、真实 agent、资源预算或发布。与用户实际 Windows 窗口的本轮核验和失败路径见实际测试报告；旧固定源对照只继续约束仍保留的组件。

# ADR-0028：显式复制所选原终端的当前可见页

- 日期：2026-11-24
- 状态：已接受方向；实现／实际平台验证另记
- 需求：FR-02/03/04/11/12；关联 FR-06 的可见页局部读取；能力：FL-002/003/005/007/012/013/018/019
- 扩展 ADR-0016/0018；不改变终端托管、存储或 agent 状态合同

## 决定

1. 沿固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 pane_copy.go／home.go／hotkeys.go，管理焦点 `V` 复制列表所选本地 Session 的新鲜可见终端页，允许所选项与活动 Tab 分开。终端焦点、原生复制模式内的 `V` 仍输入原程序。组标题不复制，不把 manager 装饰、缓存预览、历史或其他 Tab 内容混入。
2. 通过原 Backend ID／初始 Pane ID 直接执行新的 capture-pane，不使用 Preview 的历史起点，不切 Tab、不 attach、不 resize 或写入子程序。捕获前后核对 Session／Run、原 pane；未知／变化拒绝，不转投新 Run。发现／捕获／后验检查仍非原子快照，不声称消除外部并发间隙。
3. 归一化沿固定来源：去 ANSI／控制字符、CRLF 转 LF，保留内部缩进／空行／Tab 和可见链接文字，每行去右侧空格／Tab，去末尾空行。空结果明确提示而不覆盖剪贴板。原始捕获以既有 2 MiB 传输界限防御；截断、除旧式 C1 VT 控制外的原始无效 UTF-8，以及去 VT 后仍无效的文字均拒绝；不让 Strip 静默吞掉损坏字节，归一化 payload 至多 64 KiB，超限拒绝而非部分复制。这些是防御边界，不是资源预算或完整历史承诺。
4. 每个 UI 只允许一个显式可见页捕获。请求绑定原目标及当前工作区代次；捕获中移动列表选择不会转投，切 Tab／关闭／进入模态／连接失效会取消未发送请求。回执核对请求身份、代次和原目标；旧回执丢弃，不自动重试，不因同名或新运行替代目标。
5. 显式复制与原生选区复制共用既有外层终端 OSC52 提交通道，任何时刻仅一个 host 请求在途。独立单调请求令牌防止同一工作区代次里的旧完成回执释放新请求；工作区代次只判断视图新鲜度。原生读取器保持单个，最多一个最新待提交原生 payload，加一个已接受的显式捕获／payload；显式结果等待已发请求完成，之后才提交，不覆盖／重放已发请求。未发送的旧代次内容不跨 Tab 重放。
6. 外层终端写入只使用锁定稳定 v2 的 SetClipboard／Sequence，不读取原剪贴板、不反馈给子程序、不新增原生助手或后台服务。提示仅为“已向终端发送复制请求”，带显式目标／行数；不把框架输出当作 Windows 系统剪贴板持久化成功。重复 V、结果不确定与超时不自动重放。
7. Manager 的能力委派不读写数据库；不保存新输出记录、消息或历史，schema／依赖／tokens 不变。来源 normalize／capture 调用、后端进程合同、真实 Tea 事件循环 OSC52 与 Windows 独立系统剪贴板证据分别记账；本轮上传授权缺口继续有效，不换通道绕过。

## 取舍与验证

来源 native／OSC52 fallback 链与本产品既有外层终端通道不同，按 ADR-0018 保留明确平台适配。原生复制模式负责滚动／选择，V 只捕获当下后端可见页，不扩展为聊天历史或 agent 上下文。复制已退出但仍保留 pane 的屏幕不等于 agent 存活或完成。

TDD 验证选中／活动分离、可见页参数／原 pane、后验失效、归一化与上限、单次捕获、过期代次、跨 Tab／同代次重复回执、两类复制串行及原输入不变。来源精确指纹、实际证据与未验证项写入 Feature Ledger 和独立报告，接受方向不等于完整 UI 或发布接受。

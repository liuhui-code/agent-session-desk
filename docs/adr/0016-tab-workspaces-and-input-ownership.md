# ADR-0016：Tab 工作区与终端输入归属

- 日期：2026-11-23
- 状态：已接受，落实 ADR-0014/0015 已授权的工作区方向
- 实现与验证状态：首个 psmux Tab UI 切片已实现；局部测试与桌面证据见[执行报告](../testing/results/2026-11-23-tab-workspaces.md)，完整界面还原和发布验收仍开放
- 关联需求：FR-01、FR-02、FR-03、FR-04、FR-05、FR-11
- 关联功能：FL-001、FL-002、FL-003、FL-004、FL-005、FL-006、FL-012、FL-015、FL-016、FL-018
- 细化：[ADR-0014](0014-upstream-ui-tabs-and-general-terminals.md)、[ADR-0015](0015-pinned-psmux-native-terminal-client.md)；不改变后端的进程所有权

## 背景与约束

原先列表／只读预览后全屏 attach 的入口无法满足操作时持续显示 Tab 的要求。原生传输已单独验证，UI 需要恢复真实终端光标和输入，同时确保管理快捷键不会意外进入程序、已输入内容不会在切换时丢失或发给别的 Run。

## 决定

1. 支持原生终端传输的后端默认进入 Tab 工作区。每个 Tab 有独立临时 View ID，绑定完整 Session ID / Run ID；列表重排不改变绑定。首次发现可打开现有终端，关闭后不因轮询自动重开；列表 Enter 可重新打开原 Run。当前不持久化 Tab 排序或关闭状态，也不复制命令行草稿，草稿由原终端程序保存。
2. UI 同时只连接一个活动终端，关闭／切换只关闭客户端；其余终端由 psmux 保持运行。Unix tmux 暂沿用显式全屏 attach；后端能力声明决定入口，不能把未支持的传输暴露成空白 Tab。后台 Run 是否仍在输出与 agent 是否存活仍分别判断。
3. 初始终端焦点直接转发文字、已支持特殊键和显式粘贴；`q`、`Ctrl+C` 交给子程序。`F6` 切管理焦点；`Ctrl+PgUp/PgDn` 切 Tab。管理焦点下列表选择与 Enter、`n` 新建、`x` 关闭视图、`h` 只读历史、`a` 辅助全屏 attach、`q` 退出。快捷键与外层终端映射冲突需要实际验证；粘贴键由外层终端配置决定，不把 Ctrl+V 伪造为跨终端保证。
4. 原生输入由一个有界 FIFO 串行写入，包括尺寸与刷新。切换前等待旧连接已接受的写入完成；切换后的新输入只进入新目标。连接中输入受限缓存；连接尚未完成时拒绝新的 Tab 切换并显示状态，避免将原目标的输入转给另一个 Run。写入错误立即断开并停止，不自动重放。队列与字节限制是防御边界，不是任务队列或已验收性能预算。
5. 打开历史、帮助、创建表单、辅助 attach、关闭 Tab 和正常退出前等待已排队输入写完。隐藏原生视图时断开其客户端；返回后重新核对目标。读取消息与连接代次绑定，旧连接结果不能覆盖新 Tab。模型关闭清除未发送输入及表单数据。
6. 接收端仅保留最新屏幕，UI 连续读取，不按按键重建整段历史；活动可见终端约每秒请求一次最终屏幕兜底，隐藏或存在待写输入时不发起刷新。窗口尺寸改变通过 FIFO 发送，连接过程中发生的尺寸变化在连好后校正。目标输出仅渲染受验证的文字／SGR 字符属性，不能直接执行其控制序列。
7. 新建终端采用上游居中圆角对话框和 v2 Bubbles textinput，字段为名称、executable、cwd、可选 JSON 字符串数组 args。保留字面路径与参数边界，不按空格拆命令。创建需显式提交；返回 Session ID 后仍报错时展示不确定结果并禁止同表单重试，防止元数据失败引发重复进程。无额外日常聊天输入框。本切片不提供 env 编辑或 TOML 保存。
8. 上游 35% 管理侧栏、18% 终端侧栏、圆角框与 Tokyo Night 调色板进入 design tokens；窄于 80 列时，终端焦点展开终端，管理焦点在 50–79 列上下排列列表与终端，低于 50 列或高度不足时只显示列表，Enter 返回原终端。Tab 栏持续保留。应用焦点／边框／弹窗样式均使用 tokens。Tab 点击是产品适配；子程序鼠标、滚动历史、Tab 排序、列表密度／搜索仍需后续切片，不以单次画面等同完整上游体验。

## 比较过的方案

继续默认全屏 attach 无法保留 Tab 导航；为每个 Tab 常驻客户端增加连接和刷新成本；另建聊天框会改变 shell 与 agent 的原生交互。当前选择一个活动原生连接，保留辅助 attach 和可核对的失败边界。

## 后果与验证

Bubbles 2.2.2 首次作为直接依赖加入；它要求的 runewidth 0.0.31 与 uniseg 预发布提交一并精确锁定，不能将传递依赖描述为全为稳定发行。见 ADR-0005、TECH_STACK 和 go.sum。

局部测试需覆盖真实光标到最后单元格、Tab 身份、输入焦点、Unicode／多行粘贴、关闭重开、输入排空、创建参数和小窗口边界。真实 Windows 桌面需另验 A→B→A 草稿、命令独立观测、UI 重启、窗口缩放、IME 与对话框。没有安装目标 agent 的环境仍只能证明普通 shell 与测试 fixture，不能声明真实 agent 兼容或完整发布通过。全部 339 项 catalog 保留 designed/not_run，实际局部结果单独记录。

同日修复补充：初始创建弹窗的子样式 SGR reset 使行末空白显示外层背景；已用既有 formText 角色填充，保持 tokens 单一入口。RED→GREEN、43 项 Windows 顶层 UI 测试与实际画面见[背景修复报告](../testing/results/2026-11-23-dialog-surface.md)，不提升完整还原或发布状态。

同日交互补充：Tab 栏已有 token 管理的 `+`／`×` 入口和长标题上限。后台视图关闭不更换活动连接，活动视图关闭复用排空路径；本轮有鼠标点击与原 Run／草稿核对。见[交互报告](../testing/results/2026-11-23-tab-controls.md)。此实现不改变关闭与停止的架构边界，排序／滚动与其他鼠标能力仍待做。

同日生命周期补充：Start 成功后失效旧发现请求，按同一 Session/Run 对账已发现记录／Tab；关闭最后视图与空工作区回管理焦点。连接失败后只显示上次已观察的内存屏幕，取消输入权限并清除未发送缓冲，显式重查前不重放。该缓存不是持久输出或 agent 上下文。确定时序回归与 51 个 Windows 顶层 UI 测试、真实 shell 的断开只读流程见[报告](../testing/results/2026-11-23-workspace-reconciliation.md)。

比例交互补充：管理焦点 `<`／`>` 每次调整 5%，夹取 10%–90%；宽屏分隔符支持抓取／拖动，手动比例解除自动紧凑侧栏，`=` 恢复自动 35%／18%。沿用上游 2 列抓取容差、1500ms 提示，计时器最多一个；所有值经 tokens。终端焦点下操作符不截获。比例仅存当前 UI，未隐式写 TOML，保留原配置边界；不是已实现上游配置持久化。来源、失败驱动诊断和实际宽度见[报告](../testing/results/2026-11-23-workspace-split.md)。

响应式补充：管理上下布局沿用百分比及列表最少 5 行，原生终端另留边框与最少 3 行内容；不足时退到单列。单列隐藏终端期间不主动刷新，不销毁其 Run 或复制输入草稿；重新连接前仍核对身份。隐藏状态切 Tab 不留下未完成转换；正在排空／连接的切换暂缓 F6，避免已接收的新目标输入停留在缓存。Windows 实际观察为 63／49 列，原 shell 草稿与恢复后的输入均保留，见[报告](../testing/results/2026-11-23-workspace-responsive.md)。这是 Tab 终端与原列表／预览布局的适配，不宣称完全同构。

列表鼠标补充：单击按实际可见窗口选择会话，Enter／同目标 500ms 内双击经既有 Tab 打开路径进入终端，不向子程序提交 Enter；提示行／空白不选会话，分隔符优先。Session/Run 与位置共同核对同目标，键盘／缩放／其他点击打断序列。连接中被拒绝的切换不改变输入焦点；已明确请求的待切目标则允许 Enter 进入该完整身份。三种布局、两条原 shell 的真实鼠标及 PID 对账见[报告](../testing/results/2026-11-23-workspace-list-mouse.md)，不等同子程序鼠标或 scrollback。

IME 验证补充：不修改产品代码，限定 Windows 10／Microsoft 拼音下已观察到 Tab 与表单的真实候选、Space 确认和 Esc 取消；后端独立屏幕证明预编辑未提前进入 Run，确认不等于命令提交。直接 PowerShell 对照同样成功，全部 Caps／终端设置已恢复。实际范围、首轮聚合断言错误与仍未验证的切换键／焦点／辅助 attach 见[报告](../testing/results/2026-11-23-ime-composition.md)，不扩成全 IME 或发布保证。

滚轮补充：按当前指针区域区分列表与终端内容；列表滚轮选择会话并进入管理焦点，终端区域保持键盘焦点不变并委托原生滚动。隐藏／切换／区域外不发滚动，滚动亦须在切 Tab 前排空。复制模式显示历史与原生提示并隐藏实时光标；Esc／q 由 psmux 解释，不变成 shell 文字。仅最新帧，不复制历史或草稿；两轮原生窗口的 12→6→0、未提交草稿和原进程证据见[报告](../testing/results/2026-11-23-workspace-scroll.md)。完整选择／复制和目标 TUI 鼠标仍开放。

资源跟进：测试退出亦须遵循输入归属，未知焦点不发 q；只在观察管理页脚后正常退出，失败兜底不能记作正常关闭。新 Tab 资源实验已修复 UTC 时间误判，但本机测量用 ConPTY 的 F6 尚未进入可观察按键路径，run3 因此失败。只有零会话与一会话的部分阶段，不能视为 0／1／5／10 完整基线或以旧列表 UI 结果替代；根因、探针与下一步见[报告](../testing/results/2026-11-23-tab-resources.md)。正式 Go／依赖未因诊断改变，完整体验与资源门槛继续开放。

输入分界后续：同一控制台的独立原始读取器在 native 模式收到 F6、VT 模式丢失；固定 SDK measurement host 恢复 VT F6，并使同一正式产品确认管理焦点、正常 q。新的 0／1／5／10 与直接对照短基线完成，具体宿主、失败、缺口与成本见[报告](../testing/results/2026-11-23-tab-resource-host.md)。仅增加测量工具显式选项，产品输入归属和后端未改；不能据此推定系统宿主中的其他 VT 程序兼容，或将上游诊断开关升级为生产支持。

默认侧栏卡片补充（2026-11-23）：固定上游 compact 默认对应两行，28 列以下退到单行；活动终端和管理选择分别用 `┃`／`▶`，选中／活动使用 surface。渲染、窗口和鼠标共用卡片高度，元信息行选中所属 Session，不打开或提交终端输入；仅显示已有终端观察和程序文件名，不推断 agent 状态。其他密度设置及配置持久化仍待迁移。[来源与实测](../testing/results/2026-11-23-workspace-sidebar-cards.md)不代表完整视觉接受或发布验收。

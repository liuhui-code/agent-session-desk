# ADR-0030：实时终端直接拖选交给原生复制模式

- 日期：2026-11-24
- 状态：已接受方向；实际平台验收另记
- 部分扩展／替代 ADR-0029 第 1、3 项的开始条件；其余输入归属、取消、模式观察与平台边界保留
- 关联：FR-02/03/04/11；FL-002/003/005/012/013/016/018/019

## 决定

1. 已聚焦、已连接且没有声明 WantsMouse 的实时终端可直接左键拖选，无须先按管理 v。普通按下只记本地锚点，同格运动和未拖动释放不发送原生指针、不进入复制模式、不触发复制。管理焦点第一次点击仍只聚焦；修饰键、其他按钮及原生提示编辑保持不启动。
2. 第一次实际运动使用固定 psmux `20aa1d7254ee93f64dafa059ef89341d9767470a` 的 `copy-drag-begin PANE_ID ANCHOR_COL ANCHOR_ROW CUR_COL CUR_ROW`，保存原按下锚点和当前端点，随后刷新。后续运动／释放沿 ADR-0029 的原 pane 协议与 FIFO；不补发按键／Enter，不建立本地历史、VT 或第二份文本选区。
3. 固定客户端原本在普通页内部自行选择、到边缘才交接；本产品在首次运动就交接，复用后端已有冻结页、选区和复制事件。此为明确平台适配，不能称为客户端逐帧行为完全相同。进入冻结页的时机、运动输出竞争及最后绘制选区与复制端点一致性须真实后端／桌面另验。
4. 接受起始写入不等于已进入复制模式。在首个 CopyMode 帧到达前允许同一手势沿原 FIFO 继续；观察到原生模式后再观察到退出即取消。未开始原生交接时若已有外部模式切换、WantsMouse 改变、提示编辑、尺寸／视图变化，取消旧锚点；尺寸恢复不续接。按下后跨到管理控件的运动仍归原手势，不触发 Tab／分隔符操作。
5. 声明 WantsMouse 的程序暂不接直接选择，也不以鼠标字符串或猜测按键替代程序鼠标；该缺口继续保留。帧与命令之间没有模式锁，外部客户端竞争可能让后端拒绝交接或改变后续指针接收者；不重试、不把原生写入当作复制成功。原 pane 所有权、取消不合成释放、系统剪贴板及 Windows 未执行边界不变。

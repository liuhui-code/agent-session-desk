# ADR-0060：快捷键 v1

2026-11-27；用户授权实施。独立 keybindings.toml，放元数据旁，64KiB只读、整份校验后应用。缺文件/缺项继承、空串禁用；未知/冲突拒绝，重启生效。scope=global/workspace/management，权威动作在internal/keybindings，模态和终端内部手势不属v1。

UI将匹配键投射到原动作，不执行外部命令；旧键在终端可传递，但排空/切换/启动屏障优先。全局走同一份配置；不抢已占键。帮助显示实际绑定。无数据库/Host/watcher，不扫描会话。

TDD抓到旧键绕过导航屏障，已修；原生驱动/资源证据分开。配置不能使终端不报告的修饰键生效。见[合同](../KEYBINDINGS.md)。

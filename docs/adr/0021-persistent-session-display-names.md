# ADR-0021：持久会话显示名、版本冲突与原终端身份

- 日期：2026-11-23
- 状态：已接受，落实 ADR-0014 的上游交互和 FL-004/005 重命名要求
- 关联：FR-03/04/10/11/12；FL-003/004/005/011/012/013/018/019
- 扩展 ADR-0009/0010/0012 的元数据合同，细化 ADR-0014/0016/0020；终端托管、启动快照和消息语义保持原决定

## 背景与来源

固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 的 `internal/ui/group_dialog.go` 提供重命名会话弹窗、当前值预填及光标置末尾；`home.go` 管理 `r` 打开它。弹窗沿用 `styles.go` 的紫色圆角、surface 背景、居中内容和 Enter／Esc。本产品此前 `r` 用于刷新，后端标签和 SQLite `sessions.title` 都是原启动快照，不能直接改写成新显示名后继续当成身份依据。

选择性改编上述 MIT 来源并迁至固定稳定 Charm v2；精确指纹、实际来源组件帧、RED→GREEN 和执行范围见[报告](../testing/results/2026-11-23-session-rename.md)。不迁入上游分组／远程模型。

## 决定

1. **名称是独立产品元数据。** SQLite schema v3 追加 `session_names(scope,session_id,title,revision)`，外键关联原 Session，每个作用域／Session 只保存当前一行；没有无界改名日志。后端启动标签、原 `sessions.title/command`、Session/Run/Backend/pane 身份不修改，不发送终端输入，不启动或停止进程。原发现重复到来不能覆盖已保存的显示名。
2. **明确读模型。** 原始后端发现仍保存启动快照；Manager 随后投影当前显示名并按名称／ID 排序。`Session.TitleRevision=0` 表示原快照，正数表示显示名版本。实时列表和离线 history 展示同一逻辑 Session 的当前名称；history 中的名称不是不可变历史标题，Run 时间、停止和 pane 退出证据保持原值。屏幕记录按原 Session/Run/Backend/程序核对，不把可改名称当作归属凭据；保存原启动快照仍严格拒绝字段冲突。
3. **版本比较后提交。** 调用携带打开编辑时的完整 Session/Run/Backend/程序、预期名称和版本。Manager 先重新发现原目标，再在 SQLite `BEGIN IMMEDIATE` 事务内核对原记录及预期名称／版本。并发编辑只允许一个旧版本提交；改名再改回也不能绕过版本检查。同值提交不制造新版本，版本耗尽拒绝实际变更。没有数据库锁跨越后端调用，发现与提交之间不是跨进程原子存活证明；这项操作只修改元数据。
4. **迁移与备份。** 新库直接初始化 v3，v1／v2 在同一个事务内逐步升级；冲突表或结构错误回滚，不覆盖旧源文件。只读 check／snapshot 支持 v1／v2／v3，检查不迁移；备份包含显示名，仍不包含输出记录文件。旧程序会拒绝未知 schema，回退不能直接打开 v3。完整升级／断电矩阵仍待验收。
5. **新增重命名的文本规则。** 原始输入最多 4096 UTF-8 字节、必须有效 UTF-8；在 trim 前拒绝 Unicode control 和 U+2028/U+2029。裁去首尾 Unicode 空白后，名称为 1–128 个 Unicode code point、最多 512 UTF-8 字节。内部空白、大小写、引号、分号、组合字符和 ZWJ 保留，不做 shell 解析或 NFC/NFD 归一化。输入无效时保留编辑内容，不把多行粘贴清洗成另一个名称后提交。
6. **同名允许，按稳定身份区分。** 显示名不唯一、不参与寻址或 upsert。Tab、列表和搜索的可见名称发生同名或截断碰撞时，预留 Session ID 标记，前缀从六位延长到足以区分当前对象；极窄窗口保留有界裁切，不能保证任意宽度都显示完整身份。完整控制目标始终是 ID，而非可见短串。已有创建流程的名称规则不在本切片统一收紧，`TBD-NAMING` 的完整创建／迁移合同继续开放。
7. **上游键位与弹窗。** psmux 工作区管理 `r` 编辑所选会话，`Ctrl+R` 显式刷新发现与屏幕；连接／发现失败时 `r` 保留重试。历史页 `r` 仍刷新历史，终端焦点的 r／Ctrl+R 原样传给程序。弹窗预填当前值、光标置末尾，使用真实 v2 光标和明确 PasteMsg，禁用组件独立读剪贴板。按固定来源保留紫色框／标题、surface、居中与留白；本地化文字、名称长度和短窗口裁切属于必要适配，所有样式通过 tokens。
8. **焦点、异步与失败。** 打开前等待已接受的终端写入排空，绑定按键时选择的原 Session/Run；弹窗拥有键盘／鼠标／粘贴，查询和确认不进入 CLI。发现重排不重新选目标，原 Run 被替换时拒绝提交。保存成功废弃提交前的发现结果，只更新名称／版本，不覆盖更高版本；不切到被改名的后台 Tab，返回管理焦点并接回原活动终端。提交中不重复发送，保存错误后提示返回刷新核对并禁止继续提交该编辑；不自动重试不确定提交。

## 验证与剩余范围

验证持久化／重开、原启动快照、并发／ABA、作用域与目标拒绝、v1/v2 迁移回滚、备份、改名后输出记录、输入排空、取消、后台目标／Run 替换、发现迟到、同名和宽字符／窄窗。实际执行分别记录本机、原生 Windows 模型测试和真实终端桌面，不互相替代。

本决定不新增日常聊天输入框、品牌 agent 适配、后端 rename、分组／归档或持续日志。真实 shell 草稿／原进程桌面流程、新弹窗 IME、完整上游视觉接受、真实 agent、资源和发布门槛以实际报告为准；接受决定不等于验收完成。

# ADR-0067：五会话回切先取目标，保留未受影响的已完成采样

2026-11-27，已接受；细化 ADR-0062 的缓存转交顺序、ADR-0057 的布局失效粒度。关联 FL-012／015／018。

用户确认约五个会话，回切短暂出现 Connecting，并且连续切换后蓝点消失。五会话模型循环直接复现：原代码先保存当前画面，四份缓存会淘汰即将进入的目标，随后读取已缺失的目标。另一条行为回归确认：取消一个活动采样批次时，已经成功完成且未发生尺寸变化的其他原会话结果也被全局 epoch 拒绝；连续切换可能使观察一直无法刷新直至过期。

## 决定

- 切换先按完整 Session／Run／backend 身份取出目标末帧并从缓存移除，再保存原活动画面，最后将取出的目标转交当前只读连接画面。消费缓存槽时清空底层尾项，避免隐藏引用保留。
- 仍最多四份／512 KiB 额外末帧缓存，当前工作区只有原有的一份屏幕，不增加额外常驻屏幕或连接。目标首帧／输入继续要求原连接验证；回切时无 live cursor，保留 read-only last observed 提示。六个及更多会话、超界画面、复制状态或未访问目标仍可能正常淘汰／出现连接页，不能无限保留或假称已连接。
- 每个活动采样批次只记录原有最多八个目标的布局失效标记。暂停仍取消可选采样、提高连接优先级；回执只拒绝真正受原目标布局变更影响的样本，保留同批其他已完成的有效结果。一个批次结束立即清除标记。
- 原 generation 检查、按身份隔离、三秒重排基线窗口、十五秒鲜度、持续错误／List 未知不标静默保持；取消或失败结果不延长旧观察时间。没有增加采样次数、计时器、并发 worker、数据库或常驻进程。

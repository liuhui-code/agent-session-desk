# ADR-0044：改名结束恢复原焦点与侧栏状态

- 日期：2026-11-26
- 状态：已接受，依据用户对 F2／Alt 切换后滞留管理模式的反馈
- 关联：FL-003/004/012/016/018
- 部分替代 ADR-0043 的隐藏侧栏改名后留在可见管理导航的决定

F2 是临时改名操作。开始排空已接受输入前，记录当时的终端／管理焦点及侧栏显隐；弹窗保存成功或取消时恢复该状态。从管理模式打开则仍回管理模式，从隐藏侧栏的终端打开则回隐藏侧栏的终端。不确定或失败的保存保持弹窗，连接失败继续走既有不可交互路径，不假装恢复可用终端。

Alt+J/K 本身保留当前模式，不负责退出用户明确进入的管理模式。独立与 F2 后的 A/B/A 检查分别验证；不修改原切换、FIFO、身份校验或失败时输入保护。当前发现的主要原因是改名弹窗将 focused 置 false 后没有恢复，导致后续 Alt 操作继承该状态。

验证只跑相关局部检查，见[报告](../testing/results/2026-11-26-shortcut-focus.md)。其他导致管理焦点的鼠标、F6、终端断连和完整 Windows 兼容接受仍分别处理。

# ADR-0022：默认分组导航与串行界面偏好

- 日期：2026-11-23
- 状态：已接受；落实 ADR-0014 的上游体验要求
- 关联：FR-03/10/11；FL-003/004/012/018/019
- 细化 ADR-0016/0017；不改变 Session/Run、终端生命周期及 SQLite v3

## 背景与来源

固定 Agent Deck `80494e527393b7ead00da30018e6ee7e60e9d7a0` 默认使用 grouped 侧栏，提供 Alt+V 平铺切换、一行分组标题、根组数字跳转和折叠导航。此前产品仅有扁平会话卡片；直接加入标题会使原来的等高鼠标命中错位。密度和导航分别异步写同一偏好文件也会丢失另一字段。

继续选择性改编 MIT 来源的 `home.go`、`home_flatitems.go`、`home_view_list.go` 和 `embedded_sidebar.go`，迁至既有稳定 Charm v2，样式全部经 design tokens。来源指纹、未修改组件的实际渲染与本轮局部证据见[报告](../testing/results/2026-11-23-sidebar-navigation.md)。

## 决定

1. **先恢复默认组导航。** 当前发现的全部 Session 在隐式“我的会话”组下显示，默认展开；标题计数只代表发现条数。零会话也显示组标题。它是展示结构，没有组数据库或 agent 工作状态。创建／移动／重命名自定义组、嵌套及顺序仍需后续实现；本切片不代表完整分组完成。
2. **Tab 仍为主工作区。** 管理焦点 Alt+V 切换 grouped／flat；1 选择默认组；组标题 Enter、右、l、Tab 切换展开／折叠，左先回组、再次折叠。h 保留本产品只读历史入口，是明确的上游键位差异。终端焦点 Alt+V 等键仍交给原终端；视图变化不启动、停止或重连 Run，也不发送终端文本。
3. **同一可见窗口负责渲染和命中。** 组标题一行，会话按密度占 1–3 行；鼠标和滚动不再按单一行高反算。元信息行属于同一个 Session，标题点击只切换折叠。完整侧栏恢复两列快捷键留位，紧凑终端侧栏省略留位；组名称、计数和选中颜色沿来源角色。
4. **独立偏好升至 ui.toml v2。** 保存 sidebar_density、sidebar_mode 和 default_group_collapsed；缺失文件默认 compact／grouped／展开。v1 密度文件只读加载，不因启动改写；用户显式修改后发布 v2。保留 4096 字节读取限制、严格字段／类型、同目录验证临时文件与替换。启动模板和 SQLite 不改，旧程序拒绝未知 v2；跨进程并发仍以最后成功替换为准，没有文件系统事务或断电保证。
5. **一个串行写入队列。** UI 内对整份偏好一次只写一份不可变快照，合并期间的新选择，密度与导航互不覆盖。保存失败恢复上次有效值、显示错误，不自动重试。管理退出等待已接受的保存，失败取消等待退出以便查看错误；终端写入排空仍遵循 ADR-0016。
6. **目标可见性不改变目标身份。** 切 Tab／搜索打开原目标时临时展开默认组，不自动落盘；后续显式偏好修改携带当时展开状态。退出只等待已开始的保存，不为临时展开制造保存。控制对象仍以原 Session/Run 核对。

## 代价、验证与后续

本方案可以单独验证分组标题、平铺切换与混合高度命中；代价是只有隐式默认组，不能将它宣传为完整组织能力。直接迁入上游完整树／配置模型会同时引入不属于当前产品的 agent、远程和工作树语义，因此按稳定身份逐步接入。

RED→GREEN、本机全量检查、Windows 原生 UI／配置测试单列在首轮报告；同一产品源码随后完成[限定双 shell 桌面流程](../testing/results/2026-11-23-sidebar-navigation-desktop.md)，并保留 SendKeys 大写 S 的事件路径未决。Unicode S 可用不等于物理 Shift+S 通过。同尺寸视觉接受、自定义分组、真实 agent 和资源／发布门槛仍待完成，局部证据不升级为完整体验接受。

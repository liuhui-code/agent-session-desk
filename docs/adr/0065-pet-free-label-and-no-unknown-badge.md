# ADR-0065：桌宠空闲 FREE 与未知状态无角标

- 日期：2026-11-27
- 状态：已接受，按用户明确要求实现
- 关联：ADR-0051、FL-020；仅替代原空闲文案与未知角标的表现

无待提醒事项的桌宠文案由 ASD 改为 FREE，表示当前没有待提醒事项，不推断 Agent 空闲、ready 或任务完成。未知状态保留 LINK，去掉右上角减号及其底色角标；待批准／待回答仍显示原数量与 !／?。DEMO 标记、内部数量、提醒生命周期、点击导航及窗口绑定不变。

使用既有 bitmap 字体补齐 F／R 字形；尺寸、颜色、位置仍取 design tokens，不新增样式值、缓存或进程。验证用例、预览及执行边界见[报告](../testing/results/2026-11-27-pet-free-label.md)。

# 常用指令与提示词片段

main 开发版，见 [ADR-0074](adr/0074-bounded-instruction-snippets.md)及[实际验证](testing/results/2026-11-28-instruction-snippets.md)。旧公开包／日常安装不因 main 变化自动升级。

## 使用

在已连接的活动 Tab 按 **F7**，输入关键词搜索名称、ID、来源或正文。方向键选择，第一次 Enter 打开预览；上／下或 PgUp／PgDown 滚动，第二次 Enter 才向预览中显示的原终端粘贴。Esc 从预览返回列表，再按 Esc 取消；Ctrl+C 同样返回。管理焦点下仍以活动终端为目标，不跟随侧栏的另一个选择。

粘贴复用终端自身的输入区，插入后可继续编辑。确认键不进入目标，产品不追加 Enter；但正文中的换行可能让 shell 执行命令，预览会提示这一点。首次建议用单行无副作用文本核对；不能把“粘贴请求已排队”理解为 Agent 接受或任务完成。

已有输入未完成时会提示稍后再打开。弹层期间的查询、粘贴、鼠标和切换快捷键由弹层消费；原 Run／pane／连接变化或进入原生选择／搜索后拒绝插入，不在重连后补发。窗口小于 32 列／10 行时，先放大窗口再预览／确认。

## 配置位置

- **Global**：当前 `metadata.sqlite3` 同目录的 `snippets.toml`，一般是 `--state-dir`。便携缺省为包内 `data/state/snippets.toml`。完整定位见[配置说明](CONFIGURATION.md)。该目录内不同 scope 共用这份作者配置。
- **Project**：核验活动原 Run 后读取 pane 当前目录下 `.asd/snippets.toml`。当前目录变化后，下次打开重新读取；不遍历父目录、不推断 Git 根目录，不使用 UI 进程 cwd。当前目录未知时只显示 Global。

两个文件都可缺省，初始为空；产品不写入样例。用外部编辑器创建／修改后，关闭并重新打开片段库生效，不需要重启工作台。项目优先显示，各文件按 ID 排序；相同 ID 分开显示来源，互不覆盖。

```toml
schema_version = 1

[snippets.review]
title = "审查当前改动"
body = '请审查当前改动，说明问题和验证结果。'

[snippets.explain]
title = "解释设计"
body = '''请解释当前实现的设计决定。
列出边界条件与尚未验证的部分。'''
```

正文是字面文本，`${HOME}`、反引号和命令片段不会在产品中展开或执行。TOML 字符串自身仍按 TOML 规则解析；多行 literal string 开头的首个换行会被 TOML 去掉，需要精确控制末尾换行。

## 格式与容量

schema_version 固定 1，仅接受 `snippets` 映射及每项 `title`、`body`；字段大小写严格。ID 为 1–64 个小写 ASCII 字母、数字、`_`、`-`。每文件最多 64 项／256 KiB，单项 title 最多 120 UTF-8 字节、body 最多 4096 字节；标题和正文不能全空白，标题单行，正文允许 CR／LF／Tab，拒绝 ESC、NUL、C1 等其他控制字符。

任一现存文件格式或容量无效，本次整份加载失败；修好后重新打开，不会偷偷使用另一份。只在打开时读取两个文件；最多一个读取在途。加载有 5 秒上下文截止，但底层文件读取不保证立即中断；取消慢读取后，要等该读取结束再重开，避免积压。关闭弹层释放库与查询，未新增常驻服务、文件监控或每会话缓存。上述是防御上限，真实内存观察范围见测试报告。

## 自定义快捷键与 Agent 维护

`keybindings.toml`（重启工作台生效）：

```toml
schema_version = 1
[workspace]
snippets = "alt+i"
```

设置为空字符串可禁用，冲突按[快捷键合同](KEYBINDINGS.md)拒绝。弹层内 Enter／Esc 等固定键不属于可重绑动作。

后续 Agent 可维护项目 `.asd/snippets.toml`，保留其他条目、写合法 schema 并向用户说明变更；登记片段不代表批准执行。无需品牌 SDK 或额外 CLI 协议，不要往片段中存凭据，不把用户全局文件／运行数据提交 Git。

旧程序不识别新增的 `workspace.snippets` 动作；若配置过它，回退到旧程序前先移除该项。片段文件本身为独立只读文件，不涉及数据库迁移。

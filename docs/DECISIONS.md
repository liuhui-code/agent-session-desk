## 2026-11-21：补充人工介入提醒

用户确认将提醒方案纳入项目记录和相关测试。新增 FR-14、FL-020 与 ADR-0006，补充既有 attach、按能力状态与共享 Host 方向，不替换 ADR-0002/0003/0004。事项、已读/稍后、信号新鲜度与通知结果分别记录；通知只定位，不执行批准。当前所有新增能力仍为计划，测试为 designed/not_run；具体接口、系统集成与预算继续通过 O-013 和登记的 TBD 追踪。

## 2026-11-21：开始 M0 源码迁入

按用户“原始代码搬迁复用，开始执行”的要求落实既有 ADR，首批迁入五个派生源码文件；固定版本、完整许可及修改点见[复用清单](REUSE_MANIFEST.md)。这一切片未改变语言、UI 主版本、终端后台或后续存储方向，因此补充既有 ADR 的实施证据，没有另立替代决定。

M0 使用后端 user option 做存活终端的发现，不建立临时 JSON 文件数据库，也不声称具有 SQLite 历史。直接 argv 模式不自动选择 shell；脚本通过用户显式选择 shell 启动。根据稳定源码发现的参数改写明确拒绝，支持边界见[开发指南](M0_DEVELOPMENT.md)。`q` 只退出管理器，`stop SESSION_ID` 明确结束目标后端会话；归档、删除、复原同一 Session 等剩余语义继续待定。
